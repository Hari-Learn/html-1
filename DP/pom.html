Test Automation

Page Object Model (POM)

Encapsulates UI elements and actions for each page.

🧩

Encapsulation

Keeps page elements and their interactions inside dedicated page classes.

♻️

Reusability

Reuse common actions across multiple test cases without duplicating code.

🛠️

Maintainability

UI changes can be updated in one place instead of every test.

Example Structure

class LoginPage:
    username = "#username"
    password = "#password"
    login_button = "#login"

    def login(self, user, pwd):
        fill(self.username, user)
        fill(self.password, pwd)
        click(self.login_button)
POM separates test logic from page-specific UI details.
