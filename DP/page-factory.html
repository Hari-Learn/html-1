Selenium Automation

Page Factory

Simplifies initialization of page objects, commonly used with Selenium.

⚙️

Easy Initialization

Automatically initializes web elements inside page object classes.

🔍

Web Elements

Uses annotations such as @FindBy to locate elements.

🚀

Cleaner Code

Reduces repetitive element initialization and improves readability.

Selenium Example

public class LoginPage {

    @FindBy(id = "username")
    WebElement username;

    @FindBy(id = "password")
    WebElement password;

    @FindBy(id = "login")
    WebElement loginButton;

    public LoginPage(WebDriver driver) {
        PageFactory.initElements(driver, this);
    }
}
Page Factory makes Selenium page object initialization simpler and more organized.
