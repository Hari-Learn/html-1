Dirty Flag

Smart Recalculation

Improve game performance by recomputing values only when needed. The Dirty Flag pattern avoids unnecessary calculations by marking data as "dirty" whenever it changes, updating it only when it is actually required.

⚡ Faster Updates

Skip expensive calculations until data changes.

🎯 Efficient Rendering

Refresh only the objects that actually need updating.

🚀 Better Performance

Reduce CPU usage and improve frame rates in complex scenes.
