SOFTWARE TESTING

Metamorphic Testing

A testing technique that checks whether related inputs produce outputs that follow an expected relationship.

Core Idea

📥

Input

Provide an original test case.

🔄

Transform

Create a related input.

🔍

Compare

Check the expected output relation.

Metamorphic Relation

It defines how the output should change when the input is transformed.

f(x) = y
f(transform(x)) = expected(y)

Example

For a sorting function, adding an element and sorting again should produce a correctly ordered list containing that element.

Benefits

  • ✓ Useful when exact expected outputs are difficult to determine
  • ✓ Finds inconsistencies between related executions
  • ✓ Works well for complex input-output systems
  • ✓ Reduces dependence on manually generated test oracles
Metamorphic Testing • Test relationships, not just individual outputs.
