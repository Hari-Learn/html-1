Functional Programming

Higher-Order Functions

Functions that take functions as arguments or return functions.

📘 What is a Higher-Order Function?

A Higher-Order Function (HOF) is a function that either accepts one or more functions as parameters or returns another function. They are commonly used in functional programming to create reusable and expressive code.

✔ Accepts Functions

A higher-order function can receive another function as an argument and execute it.

✔ Returns Functions

A higher-order function can return a new function for later use.

💻 Example 

// Higher-Order Function
function greet(name, callback) {
  const message = "Hello " + name;
  callback(message);
}

function display(text) {
  console.log(text);
}

greet("Alice", display);

// Output:
// Hello Alice

⭐ Common Higher-Order Functions in JavaScript

map()

Transforms each element and returns a new array.

filter()

Returns elements that satisfy a condition.

reduce()

Combines array elements into a single value.

🚀 Benefits

  • Promotes code reuse.
  • Improves readability and maintainability.
  • Encourages functional programming practices.
  • Reduces duplicate code.
  • Makes programs more modular and flexible.

Summary

A Higher-Order Function is a function that takes one or more functions as arguments, returns a function, or both. They are fundamental to JavaScript and functional programming, enabling powerful abstractions through functions like map(), filter(), and reduce().
