Here’s a compact Tailwind page under 100 lines that visually explains the **Actor Pattern** and its relationship to the **Screenplay Pattern**. ``` Actor Pattern
Test Automation Pattern

Actor Pattern

Represents a user or system actor performing tasks and interactions; commonly associated with the Screenplay Pattern.

👤

Actor

Represents the user or system performing an action.

🎯

Task

Defines a meaningful business activity performed by the actor.

🖱️

Interaction

Describes actions the actor performs with the system.

Screenplay Example

Actor user = Actor.named("Alice");

user.attemptsTo(
  Login.withCredentials("alice", "secret"),
  Search.forProduct("Laptop"),
  AddToCart.theProduct()
);

Why use the Actor Pattern?

Readable

Tests describe behavior in user-focused language.

Reusable

Tasks and interactions can be shared across tests.

Scalable

Separates business behavior from UI details.

```
