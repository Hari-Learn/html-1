Messaging

Scatter-Gather

Send requests to multiple services in parallel and aggregate their responses into a single result, improving responsiveness and enabling distributed processing.

📤

Scatter Requests

Broadcast or send the same request simultaneously to multiple services or consumers.

⚙️

Parallel Processing

Each service processes the request independently, reducing overall response time.

📥

Gather Results

Collect and combine responses from all participating services into one unified result.

Typical Workflow

Client
→
Scatter Request
→
Multiple Services
→

Key Concept

The Scatter-Gather messaging pattern distributes a request to multiple services, waits for their responses, and aggregates the results before returning a final response to the client. This approach is ideal for search aggregation, pricing services, recommendation engines, and other distributed systems that benefit from parallel execution.
