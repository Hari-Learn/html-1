DESIGN PATTERN

Decorated Command

Add behavior around a command without changing the command itself.

01

Command

Defines the basic operation to execute.

02

Decorator

Wraps a command and adds extra behavior.

03

Execution

Runs logging, validation, retry, or other logic.

Example

JavaScript 
class Command {
  execute() {}
}

class SaveCommand extends Command {
  execute() { console.log("Saving..."); }
}

class LoggingDecorator extends Command {
  constructor(command) { super(); this.command = command; }
  execute() {
    console.log("Before command");
    this.command.execute();
    console.log("After command");
  }
}

const command = new LoggingDecorator(
  new SaveCommand()
);
command.execute();
