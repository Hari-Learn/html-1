Testing Pattern

Scenario Object Pattern

Represent a test scenario as an object containing setup, actions, and expected outcomes.

⚙️

1. Define Setup

Capture the initial state, inputs, users, data, and other conditions required before the test begins.

▶️

2. Describe Actions

Store the operations performed during the scenario as explicit, reusable actions.

🎯

3. Define Outcomes

Keep expected results alongside the scenario so the test clearly describes what success looks like.

Scenario Object

// A complete scenario in one object
scenario = {
setup: "customer has an account",
action: "place an order",
expected: "order is confirmed"
};

Why use it?

• Keeps test data structured
• Separates scenarios from execution logic
• Makes scenarios easy to reuse
• Simplifies parameterized testing
A Scenario Object turns a test case into structured data, making complex scenarios easier to compose, reuse, and maintain.
