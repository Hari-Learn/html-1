Robot Pattern

Represents the UI as high-level user actions rather than exposing low-level locators, making tests easier to read and maintain.

🤖

High-Level Actions

What the user wants to do

loginAs("Alice")
searchFor("Laptop")
addToCart()
⚙️

Hidden Details

How the UI action is performed

Find username field → type value
Find search box → enter query
Find Add button → click

Robot Example

const shop = new ShoppingRobot(page);

shop.loginAs("Alice");
shop.searchFor("Laptop");
shop.addToCart();

expect(shop.cartItemCount()).toBe(1);

Readable

Tests describe user behavior clearly.

Encapsulated

Locators remain inside the robot.

Maintainable

UI changes require fewer test updates.
