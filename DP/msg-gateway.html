INTEGRATION PATTERN

Messaging Gateway

Provides a simple application-level interface for sending and receiving messages through a messaging system.

What is Messaging Gateway?

A Messaging Gateway hides the details of a messaging infrastructure behind a clean API. Application code communicates with the gateway instead of directly interacting with queues, brokers, or messaging protocols.

Goal

Decouple business logic from messaging infrastructure.

Message Flow

Application
→
Messaging Gateway
→
Message Broker
→
Consumer

Benefits

  • ✓ Hides messaging implementation details
  • ✓ Reduces coupling with messaging infrastructure
  • ✓ Easier testing and mocking
  • ✓ Provides a business-friendly messaging API

Example

gateway.sendOrderCreated(order);

gateway.sendNotification(userId, message);
