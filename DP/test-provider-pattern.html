Test Environment Provider Pattern

Abstracts the creation and management of test environments for consistent and repeatable test execution.

🏗️

Create

Provides a standard way to provision the infrastructure required for testing.

⚙️

Manage

Handles configuration, setup, health checks, and lifecycle management.

🧹

Destroy

Cleans up environments after testing to avoid resource waste and conflicts.

Environment Lifecycle

Request
Ask for environment
→
Provision
Create resources
→
Test
Run test suite
→
Cleanup
Release resources

Example

environment = provider.create({
    browser: "Chrome",
    database: "TestDB",
    services: ["API", "Auth"]
});

runTests(environment);

provider.destroy(environment);
