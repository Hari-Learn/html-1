Test Automation Pattern

Record & Replay Pattern

Records real user interactions and replays them automatically during tests.

🎥

Record

Captures clicks, typing, navigation, and other user interactions.

▶️

Replay

Repeats the recorded actions automatically against the application.

📊

Validate

Checks whether the application behaves as expected during replay.

How It Works

User Action
Interact with app
→
Record
Capture actions
→
Replay
Run automatically
→
Result
Verify behavior

Example Scenario

1. Open Login Page
2. Enter username
3. Enter password
4. Click Login
5. Verify Dashboard

→ Record these interactions
→ Replay them during regression tests
→ Compare actual vs expected results
