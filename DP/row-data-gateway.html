Row Data Gateway Pattern

Represents a database row as an object.

Overview

The Row Data Gateway Pattern is an enterprise application architecture pattern where each object represents a single row in a database table. The object contains both the data and the methods needed to retrieve, update, insert, or delete that row, providing a straightforward mapping between database records and application objects.

Characteristics

  • One object per database row
  • Encapsulates row data
  • Provides CRUD operations
  • Simple database mapping

Advantages

  • Easy to implement
  • Simple object-relational mapping
  • Encapsulates database logic
  • Suitable for small applications

Limitations

  • Can become repetitive
  • Not ideal for complex domains
  • Business logic may be duplicated
  • Less scalable for large systems
