Table Data Gateway Pattern

Provides an object interface for database tables.

Overview

The Table Data Gateway Pattern is an enterprise application architecture pattern that encapsulates all database operations for a single table within one gateway object. Instead of creating one object for each row, a single gateway class manages queries, inserts, updates, and deletes for the entire table.

Key Features

  • One gateway per database table
  • Centralizes SQL operations
  • Provides CRUD methods
  • Encapsulates database access

Advantages

  • Reduces duplicate SQL code
  • Easy to maintain
  • Improves code organization
  • Simplifies data access

Limitations

  • Business logic remains separate
  • Large gateway classes may grow complex
  • Less suitable for rich domain models
  • May require multiple joins manually
