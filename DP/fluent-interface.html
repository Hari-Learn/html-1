💡 API Design Pattern

Fluent Interface

Chain method calls for readability.

The Fluent Interface pattern improves API usability by allowing methods to return the current object, enabling expressive, readable, and naturally flowing method chains.

🔗

Method Chaining

Connect multiple method calls into a single, elegant statement.

📖

Readable APIs

Create APIs that resemble natural language and are easier to understand.

⚡

Developer Friendly

Reduce boilerplate and make object configuration clean and intuitive.

Example 

const query = new QueryBuilder()
  .select("*")
  .from("users")
  .where("active", true)
  .orderBy("name")
  .limit(10);
