Journey Pattern

Models an end-to-end business journey as a reusable sequence of actions, making complex workflows easier to express and maintain.

Journey Example

class PurchaseJourney {
  static complete() {
    return [
      SignUp.asNewCustomer(),
      Login.withCredentials(),
      AddProduct.toCart(),
      Pay.withCard(),
      Verify.orderConfirmation()
    ];
  }
}

Why use it?

  • ✓ Reuses complete business workflows.
  • ✓ Keeps tests focused on business intent.
  • ✓ Makes end-to-end scenarios easier to read.
  • ✓ Reduces duplicated sequences across tests.

Journey = reusable business flow → multiple actions → end-to-end outcome
