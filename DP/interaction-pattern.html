Here’s a clean single-page Tailwind HTML example, kept under 100 lines, for the **Interaction Pattern**. ``` Interaction Pattern
Test Automation Pattern

Interaction Pattern

Represents a single interaction such as clicking, typing, or calling an API.

🖱️

Click

Represents a user clicking a button, link, or other UI element.

Click.on("#login")
⌨️

Type

Represents entering information into an input field.

Enter.theValue("Alice")
🌐

API Call

Represents an interaction with a backend service or API.

CallAPI.get("/users")

Example Flow

1. Click

Login

→
2. Type

Credentials

→
3. Call

API

Focused

One interaction has one clear responsibility.

Reusable

Interactions can be composed into larger tasks.

Maintainable

Implementation details stay isolated.

```
