INTEGRATION PATTERN

Message Endpoint

Connects an application to a messaging channel and provides the interface required to send or receive messages.

What is Message Endpoint?

A Message Endpoint is the point where an application interacts with a messaging system. It hides messaging infrastructure details and handles message sending or receiving.

Purpose

Connect application logic with message channels in a controlled way.

Message Flow

Application
→
Message Endpoint
→
Message Channel
→
Consumer

Benefits

  • ✓ Separates application logic from messaging infrastructure
  • ✓ Centralizes message handling
  • ✓ Simplifies testing and maintenance
  • ✓ Supports both producers and consumers

Example

endpoint.send(orderMessage);

Message msg = endpoint.receive();
