Functional Programming

Applicative

Apply Wrapped Functions

What is an Applicative?

An Applicative allows you to apply a function that is wrapped inside a context (such as Maybe, Promise, or List) to a value wrapped in the same context. 

Function:  Just(x => x * 2)
Value:     Just(10)

Result:
Just(20)

✔ Key Idea

Instead of applying a normal function to a normal value, an Applicative applies a wrapped function to a wrapped value.

📦 Formula

F (a → b) → F a → F b

Example 

const add = x => y => x + y;

Just(add)
  .ap(Just(5))
  .ap(Just(10));

// Just(15)

Summary

Applicative extends the idea of a Functor by allowing functions inside a context to be applied to values inside the same context. This makes it possible to combine multiple independent wrapped values while preserving their context.
