``` Test Data Factory
Test Automation Pattern

Test Data Factory

Centralizes generation of valid, invalid, boundary, and randomized test data.

✅

Valid Data

Creates realistic data that should pass validation.

UserFactory.valid()
❌

Invalid Data

Produces malformed or rejected test inputs.

UserFactory.invalid()
📏

Boundary Data

Targets minimum, maximum, and edge-case values.

UserFactory.boundary()
🎲

Randomized Data

Generates varied data for broader test coverage.

UserFactory.random()

Factory Example

class UserFactory {
  static valid() { return { name: "Alice", age: 30 }; }
  static invalid() { return { name: "", age: -1 }; }
  static boundary() { return { name: "A", age: 18 }; }
  static random() { return { name: faker.person.firstName() }; }
}
```
