Functional Programming

Currying

Transform Multi-Argument Functions

📘 What is Currying?

Currying is a functional programming technique that transforms a function with multiple arguments into a sequence of functions, each taking a single argument. Instead of supplying all arguments at once, you provide them one at a time.

🔄 Transformation

add(a, b, c)
⬇
add(a)(b)(c)

💻 JavaScript Example 

// Curried Function
function multiply(a) {
  return function (b) {
    return a * b;
  };
}

const double = multiply(2);

console.log(double(5));   // 10
console.log(double(8));   // 16

✨ Benefits of Currying

✔ Reusability

Create specialized functions by fixing some arguments.

✔ Partial Application

Supply arguments gradually instead of all at once.

✔ Cleaner Code

Improves readability by composing small functions.

✔ Functional Style

Encourages modular and declarative programming.

🌍 Real-World Example 

const greet = greeting => name => 
  `${greeting}, ${name}!`;

const sayHello = greet("Hello");

console.log(sayHello("Alice")); // Hello, Alice!
console.log(sayHello("Bob"));   // Hello, Bob!

📌 Summary

Currying transforms a function that accepts multiple arguments into a chain of single-argument functions. It makes code more reusable, supports partial application, and is a core concept in functional programming for building flexible and composable functions.
