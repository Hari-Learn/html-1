Result / Either

Represent Success or Failure in a clean and predictable way.

What is Result / Either?

Result (or Either) is a functional programming pattern used to return either a successful value or an error instead of throwing exceptions. This makes error handling explicit, predictable, and easier to maintain.

✅

Success (Ok / Right)

Contains the expected value when the operation completes successfully.

Result.success(User)
❌

Failure (Error / Left)

Contains an error describing why the operation failed.

Result.failure("User not found")

Benefits

✅ Avoids unexpected exceptions
✅ Makes success and failure explicit
✅ Easier to test and debug
✅ Encourages cleaner application flow

Example Flow 

Result<User, Error> result = repository.getUser(id);

if (result.isSuccess()) {
    print(result.value);
} else {
    print(result.error);
}

Summary

The Result/Either pattern wraps the outcome of an operation into two possible states: Success or Failure. This approach improves reliability by making error handling part of the application's normal control flow instead of relying on exceptions.
