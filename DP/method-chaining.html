⚡ API Design

Method Chaining

Return this from methods.

Method Chaining is an API design pattern where each method returns the current object (this), allowing multiple method calls to be linked together in a single, readable expression.

🔗

Chain Calls

Connect multiple operations into one clean and expressive statement.

📖

Readable Code

Improve code clarity by reducing repetitive object references.

🚀

Simple APIs

Build intuitive interfaces that are easy to learn and pleasant to use.

Example 

class Builder {
  setName(name) {
    this.name = name;
    return this;
  }

  setAge(age) {
    this.age = age;
    return this;
  }

  build() {
    return {
      name: this.name,
      age: this.age
    };
  }
}

const user = new Builder()
  .setName("Alice")
  .setAge(28)
  .build();
