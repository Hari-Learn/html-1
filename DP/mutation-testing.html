Test Quality

Mutation Testing

Deliberately introduce small code changes ("mutants") to determine whether the test suite catches them.

🧬

Create Mutants

Introduce controlled changes such as altered conditions, operators, or return values into the code.

🧪

Run Tests

Execute the existing test suite against each mutant to see whether incorrect behavior is detected.

🛡️

Measure Strength

Identify surviving mutants and strengthen tests where important defects go undetected.

Objective

Verify that tests can detect meaningful code changes.

Mutate → Test → Kill
Stronger tests. Fewer blind spots. Higher confidence.
