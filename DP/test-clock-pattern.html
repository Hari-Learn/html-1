Test Automation Pattern

Test Clock Pattern

Replaces real time with controllable or fake time for deterministic time-based tests.

⏰

Fake Time

Replaces the system clock with a predictable time controlled by the test.

🎛️

Control

Freeze, advance, or set the clock to specific dates and times.

🎯

Deterministic Tests

Makes time-dependent tests repeatable and independent of the real clock.

How It Works

Set Time
Choose test time
→
Run Test
Use fake clock
→
Advance
Move time forward
→
Validate
Check expected result

Example Scenario

clock.set("2026-01-01 23:59");

runTest();

clock.advanceMinutes(2);

// Application is now:
// 2026-01-02 00:01

assertNewDayStarted();
