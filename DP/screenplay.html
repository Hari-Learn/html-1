Test Automation Pattern

Screenplay Pattern

Models tests around actors, tasks, and interactions, making automated tests readable, reusable, and scalable.

👤

Actor

Represents a user or system that performs actions and has abilities.

🎯

Task

Represents a meaningful business goal performed by an actor.

⚡

Interaction

Represents individual actions an actor performs with the application.

How It Works

→
Task

→
Interactions

Example Scenario

Actor: John

Task: Login to the application

Interactions:
  Enter username
  Enter password
  Click Login

John.attemptsTo(
    Login.withCredentials("john", "secret")
);

Why Use It?

  • ✓ Business-readable tests
  • ✓ Reusable tasks and interactions
  • ✓ Clear separation of responsibilities
  • ✓ Scales well for large test suites

Key Idea

Instead of focusing on pages, the Screenplay Pattern focuses on what actors want to accomplish and the interactions they use to achieve their goals.
