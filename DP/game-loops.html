Game Development

Game Loop

Continuous update-render cycle.

🎮

Input

Read keyboard, mouse, or controller input.

➜
⚙️

Update

Update player, enemies, physics, and game logic.

➜
🖥️

Render

Draw the updated game scene on the screen.

🔄 Repeat Every Frame (≈ 60 FPS)

Pseudocode 

while (gameRunning) {
    processInput();
    update();
    render();
}
