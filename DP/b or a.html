A/B Testing

Compares different versions of a product or experience using real user behavior to determine which performs differently against a defined metric.

🅰️

Version A

The control or existing version shown to one group of users.

🅱️

Version B

The alternative version shown to another comparable group.

How It Works

01

Define a goal

02

Split users

03

Run the experiment

04

Analyze results

📊 Common Metrics

  • • Click-through rate
  • • Conversion rate
  • • Sign-ups
  • • Revenue per user

💡 Example

Test two checkout buttons with real users and compare their conversion rates to understand whether the change affects user behavior.

A/B Testing • Make product decisions with measurable user behavior.
