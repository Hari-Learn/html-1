Leaky Bucket Pattern

The Leaky Bucket pattern is a rate-limiting algorithm used to control the flow of requests. Incoming requests are placed into a bucket (queue), and they leave the bucket at a constant rate. If the bucket becomes full, additional requests are discarded.

How It Works

  1. Create a bucket with fixed capacity.
  2. Incoming requests enter the bucket.
  3. The bucket leaks requests at a fixed speed.
  4. If the bucket is full, new requests are rejected.
  5. This produces a smooth, predictable output rate.

Flow

Client → Bucket Queue → Constant Leak Rate → Server

Java Example


class LeakyBucket {

    Queue bucket = new LinkedList<>();
    int capacity = 5;

    boolean add(String request) {
        if(bucket.size() == capacity) return false;
        bucket.offer(request);
        return true;
    }

    void process() {
        if(!bucket.isEmpty())
            System.out.println(bucket.poll());
    }
}

Advantages

  • Controls traffic spikes.
  • Provides steady request processing.
  • Protects servers from overload.
  • Easy to understand and implement.
  • Improves system stability.

Disadvantages

  • Burst traffic may be dropped.
  • Queue size must be configured carefully.
  • Can increase request latency.

Common Use Cases

  • API gateways
  • Network traffic shaping
  • Load balancers
  • Message processing systems
  • DDoS protection
Key Idea: Unlike the Token Bucket algorithm, the Leaky Bucket processes requests at a constant rate, producing a smooth and predictable output even when incoming traffic arrives in bursts.
