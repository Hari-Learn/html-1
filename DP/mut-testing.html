SOFTWARE TESTING

Mutation Testing

A technique for evaluating the effectiveness of a test suite by introducing small, deliberate changes into source code.

🧬

Mutation

Create small defects called mutants by modifying the code.

🧪

Run Tests

Execute the existing test suite against each mutant.

📊

Measure

Use mutation scores to understand test-suite strength.

How It Works

1. Start with working production code.

2. Apply mutation operators such as changing + to -.

3. Run the test suite against the mutated code.

4. A mutant is killed if a test detects the change.

5. A mutant that survives indicates a potential testing gap.

Mutation Score

Killed Mutants / Total Mutants × 100

A higher score generally means more introduced faults are detected by the tests.

Common Operators

  • • Arithmetic operator changes
  • • Relational operator changes
  • • Boolean expression changes
  • • Statement deletion
