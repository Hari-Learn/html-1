``` Object Mother Pattern
Test Data Pattern

Mother Object / Object Mother

Provides predefined test-object configurations such as validUser() and adminUser().

The Idea

Instead of creating complex test objects repeatedly, an Object Mother centralizes reusable, meaningful configurations.

UserMother.validUser()
UserMother.adminUser()

Example

class UserMother {
  static validUser() {
    return {
      name: "Alice",
      role: "USER",
      active: true
    };
  }

  static adminUser() {
    return {
      ...this.validUser(),
      role: "ADMIN"
    };
  }
}

Why use it?

♻️

Reusable

Avoid duplicate test setup.

🎯

Readable

Tests express intent clearly.

🧩

Maintainable

Change defaults in one place.
