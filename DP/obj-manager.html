Object Lifetime Manager

Controls the creation and destruction of shared objects while simplifying ownership, lifecycle coordination, and resource cleanup.

♻

What it does

The Object Lifetime Manager provides a centralized mechanism for managing shared objects. It determines when objects should be created, reused, and ultimately destroyed.

By separating lifetime management from application logic, components can safely share resources without each component having to manage the complete lifecycle independently.

Core Responsibility

Controls creation/destruction of shared objects
