AI Security

Prompt Injection Defense

A practical defense layer for keeping untrusted instructions from controlling your AI agent.

01

Treat Input as Untrusted

User messages, web pages, documents, emails, and tool results may contain instructions designed to manipulate the model.

02

Separate Instructions

Clearly distinguish trusted system instructions from untrusted data and retrieved content.

03

Limit Tool Permissions

Give agents only the tools and permissions required for their task. Use least privilege by default.

04

Require Approval

Add human approval before external side effects such as sending, deleting, purchasing, or publishing.

Defense checklist

  • ✓ Validate tool arguments
  • ✓ Never expose secrets to the model unnecessarily
  • ✓ Keep retrieved content separate from trusted instructions
  • ✓ Apply least-privilege permissions
  • ✓ Log sensitive actions
  • ✓ Add human approval for high-impact operations
Defense in depth beats relying on a single prompt rule.
