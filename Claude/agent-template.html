Prompt Templates

Create reusable instructions for consistent AI results.

What is a prompt template?

A prompt template is a reusable structure with placeholders that can be changed for different tasks.

Example Template

Role-based prompt

You are a [ROLE].
Your task is to [TASK].
Target audience: [AUDIENCE].
Output format: [FORMAT].
Tone: [TONE].
Include practical examples.

Example in action

You are a Python tutor. Explain loops to beginners using three examples and a short quiz.

Best practices

  • Use clear placeholders.
  • Define the expected output format.
  • Specify the audience and tone.
  • Save prompts that work well.
