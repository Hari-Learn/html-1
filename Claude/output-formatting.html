Output Formatting

Control how Claude presents information using explicit instructions.

Tables

Best for comparisons and structured summaries.

Create a table with
Name, Price, Features.

JSON

Best for APIs and machine-readable data.

Return valid JSON with
"name" and "category".

Markdown

Best for readable documents and reports.

Use headings, bold text,
and short paragraphs.

Lists

Best for steps, checklists, and key points.

Give 5 numbered steps
in execution order.

Example JSON Output

{
  "topic": "Prompt Engineering",
  "level": "Beginner",
  "skills": ["XML", "JSON", "Markdown"]
}

Pro Tip

Specify the exact format, required fields, item count, and whether extra commentary is allowed. Validate JSON when strict machine-readable output is required.
