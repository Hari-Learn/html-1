BM25 Search

Best Matching 25 is a keyword-based information retrieval algorithm used to rank documents based on search terms.

How BM25 Works

  1. Receive the user's search query.
  2. Tokenize the query into keywords.
  3. Find matching terms in documents.
  4. Calculate term frequency (TF).
  5. Calculate inverse document frequency (IDF).
  6. Rank documents using BM25 scores.

BM25 Formula

BM25(D,Q) = Σ IDF(q) × TF(q,D)

The ranking considers term frequency, document length, and how rare a keyword is across the document collection.

Advantages

Fast, interpretable, effective for exact keyword matching.

Limitations

Cannot naturally understand meaning or synonyms.

Real-World Applications

Search engines, document search, e-commerce search, and knowledge bases.
