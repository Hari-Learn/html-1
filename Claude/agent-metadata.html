Claude: Usage Metadata

Rare Topic 21 | CCAO-F Notes

1. What is usage metadata?

Information returned by the API that helps developers understand how many tokens and other resources a request used.

Think of it as an itemised usage receipt.

2. Important fields

  • input_tokens — input tokens counted for the request.
  • output_tokens — generated output tokens.
  • cache_read_input_tokens — tokens read from prompt cache.
  • cache_creation_input_tokens — tokens written to prompt cache.

3. Tool usage can be separate

Some server-side tools report their usage separately from token counts.

Example field:

server_tool_use

For web search, it can include web_search_requests.

4. Example response data

{
  "usage": {
    "input_tokens": 105,
    "output_tokens": 603,
    "cache_read_input_tokens": 0,
    "cache_creation_input_tokens": 0,
    "server_tool_use": {
      "web_search_requests": 1
    }
  }
}

Illustrative example only.

5. Why should developers monitor it?

  • Estimate API usage and cost.
  • Identify requests consuming many tokens.
  • Understand prompt-cache usage.
  • Monitor additional server-tool activity.
  • Compare usage across application features.

ELI10: Restaurant bill analogy

Input tokens are like ingredients you bring. Output tokens are the food prepared. Cached tokens show reuse of prepared ingredients. A web search can be an additional service charge.

The exact bill depends on the model, token categories, and tool pricing.

Exam Scenario

An application uses Claude's web search tool. The developer wants to monitor search activity separately from token usage. Which usage field should be inspected?

Reveal answer

server_tool_use, including the web_search_requests count when provided.
