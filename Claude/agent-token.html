Lesson 03: Tokens and Parameters

Tokens and Parameters

1. Token Management

A token is a small piece of text processed by an AI model.

Example: "Hello world" may be split into multiple tokens.

max_tokens controls the maximum number of tokens Claude can generate in its response.

2. Temperature

Temperature influences the randomness of generated answers.

Lower = more predictable. Higher = more varied.

3. Model Parameters

  • Model: Selects which Claude model to use.
  • max_tokens: Limits response length.
  • temperature: Controls randomness where supported.
  • stream: Enables streaming responses.

API Example

{
  "model": "claude-sonnet-4-5",
  "max_tokens": 500,
  "messages": [
    {
      "role": "user",
      "content": "Explain AI simply"
    }
  ]
}
