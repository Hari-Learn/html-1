MODULE 01

CLAUDE.md Configuration

Configure project instructions to help Claude understand your codebase and development standards.

What is CLAUDE.md?

CLAUDE.md is a Markdown instruction file that provides Claude Code with project-specific context, coding conventions, workflows and development guidelines.

Why use CLAUDE.md?

  • Define project architecture.
  • Specify coding standards.
  • Explain folder structures.
  • Document development commands.
  • Provide testing instructions.
  • Maintain consistent coding practices.

File Structure

my-project/
├── CLAUDE.md
├── src/
├── tests/
├── package.json
└── README.md

Example CLAUDE.md

# Project Instructions

## Project Overview
React application with Node.js backend.

## Coding Standards
- Use functional components.
- Follow clean code principles.
- Use reusable components.

## Development Commands
- npm install
- npm run dev
- npm test

## Guidelines
- Write maintainable code.
- Handle errors properly.
- Add tests for new features.
- Explain important changes.

Best Practices

Keep instructions clear, concise, and relevant. Avoid duplicating information that already exists in project documentation.
