Tool Control & Handoffs

How Claude decides when and how tools are used.

1. What is Tool Choice?

Tool choice controls how Claude uses tools made available by the application.

ELI10: You give a worker access to a calculator. Tool choice determines whether they can use it, must use it, or cannot use it.

2. Common Tool Choice Modes

Auto

Claude decides whether to call an available tool.

Any

Claude must call one of the available tools.

Tool

Claude is directed to use a specific tool.

None

Claude is not allowed to call tools for that request.

3. Parallel Tool Use

Claude may request multiple independent tool calls in one response.

Only independent operations should run in parallel.

4. Tool Handoff

When Claude requests a tool, the application executes it and returns the result. Claude can then continue generating its response.

  • Claude sends a tool request.
  • Application executes the tool.
  • Tool result is returned.
  • Claude uses the result to continue.

5. Exam Scenario

Claude needs current weather and currency rates. Both tools work independently. What can improve efficiency?

Reveal answer

Parallel tool calls, because both requests can execute independently.

Remember: Tool request is not tool execution. The application executes the call.
