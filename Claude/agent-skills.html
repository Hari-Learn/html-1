MODULE 02

Custom Commands & Skills

Build reusable workflows and specialized capabilities in Claude Code.

1. Custom Commands

Custom commands allow developers to create reusable prompt workflows that can be triggered using slash commands.

Example folder structure

.claude/
└── commands/
    ├── review.md
    └── test.md

Example: review.md

---
description: Review project code
---

Review the selected code.

Check:
- Code quality
- Security issues
- Performance
- Best practices

Provide improvement suggestions.

Usage: /review

2. Claude Skills

Skills are reusable instruction packages that teach Claude how to perform specialized tasks. They can include instructions, scripts and supporting resources.

Example folder structure

.claude/
└── skills/
    └── code-review/
        ├── SKILL.md
        └── examples/
            └── sample.md

Example: SKILL.md

---
name: code-review
description: Review code for quality and security.
---

# Code Review Skill

1. Inspect the code.
2. Identify bugs.
3. Check security risks.
4. Suggest improvements.
5. Summarize findings.

3. Commands vs Skills

Custom CommandsSkills
Explicit slash invocationCan be selected based on task context
Reusable workflowsReusable specialized capabilities
Markdown promptsInstructions and supporting files

Practical Exercise

Create a custom command for code review and a Skill for generating unit tests. Test both inside a sample project.
