Claude: Code Execution Tool

Rare Topic 25 | CCAO-F Notes

1. What is Code Execution?

A server-side tool that allows Claude to write and run code to solve tasks.

It can use Python, shell commands and file operations in a managed environment.

2. When is it useful?

  • Complex calculations.
  • Analysing CSV data.
  • Creating charts.
  • Processing files.
  • Running simulations.

3. How does it work?

1. User asks for data analysis.
↓
2. Claude decides to execute code.
↓
3. Code runs in a sandbox.
↓
4. Results return to Claude.
↓
5. Claude explains the result.

4. Sandbox restrictions

  • Runs in an isolated container.
  • No internet access in the execution environment.
  • Only pre-installed libraries are available.
  • New requests usually get a new container unless one is reused.

5. Client Tool vs Code Execution

Client tool: Your application runs the function.

Code Execution: Anthropic runs code in its managed sandbox.

Remember: these are different execution locations.

ELI10 Example

You give Claude a spreadsheet with 10,000 sales records and ask for the total. Claude can write Python code to calculate it instead of manually reading every row.

Exam Scenario

A user asks Claude to analyse a large CSV file and create a chart. Which capability is suitable?

Reveal answer

The Code Execution tool. It can process data and generate charts inside the sandbox.
