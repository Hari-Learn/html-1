Lesson 02: Streaming Responses

Streaming Responses

Streaming means Claude sends its answer little by little instead of waiting to finish the entire answer.

Normal vs Streaming

Normal:

Wait... Wait... Complete answer appears.

Streaming:

Hello → Hello, how → Hello, how are you?

API Example

{
  "model": "claude-sonnet-4-5",
  "max_tokens": 1024,
  "stream": true,
  "messages": [
    {
      "role": "user",
      "content": "Explain AI"
    }
  ]
}

Try a simple streaming demo

Remember

  • Streaming sends data in chunks.
  • Users see answers sooner.
  • Claude API supports streaming using SSE.
  • Streaming is useful for chat applications.
