Claude API: Tool Search

Rare Topic 22 | CCAO-F Notes

1. What is Tool Search?

Tool Search lets Claude discover relevant tools when needed instead of requiring every tool definition to be loaded at the beginning.

Useful when an application has many available tools.

2. The problem it solves

Imagine an application has 500 tools.

  • Loading all definitions uses context.
  • Many tools may be irrelevant to the current task.
  • Large tool lists can make management harder.

3. How it works

1. Application provides tool discovery.
↓
2. Claude searches for a relevant tool.
↓
3. Relevant tool definition is made available.
↓
4. Claude can use the discovered tool.

4. Important distinction

Tool Search: helps discover a tool.

Tool Use: actually calls the tool to perform an action.

Finding a hammer is not the same as using the hammer.

5. Why is it useful?

  • Supports applications with large tool libraries.
  • Can reduce upfront tool-definition context.
  • Makes tools available when relevant.
  • Can work with deferred tool loading.

ELI10 Example

A library has 500 books. Instead of carrying all 500 books everywhere, you first search the catalogue and collect only the book you need.

Exam Scenario

An enterprise application has hundreds of tools. The developer wants Claude to find relevant tools without loading every definition upfront. Which capability is useful?

Reveal answer

Tool Search. It helps Claude discover relevant tools dynamically.
