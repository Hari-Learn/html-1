Agent Loops & Stopping Conditions

An AI agent continuously observes, plans, and acts—evaluating every result until the goal is achieved or a stopping rule is triggered.

Control layer

When should an agent stop?

Every autonomous workflow needs explicit exit rules.

Goal achieved

The task meets its defined success criteria.

Iteration or time limit

Prevent endless loops and runaway execution.

Token or budget limit

Stop when compute, API spend, or token usage reaches its cap.

Unrecoverable error

Exit safely when a tool fails repeatedly or state becomes invalid.

Human approval needed

Pause before sensitive, risky, or irreversible actions.

Best practice

Bound every loop.

Define success criteria, set execution limits, validate tool outputs, and provide a safe failure path.
