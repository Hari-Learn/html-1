Meet Claude

Claude is a family of AI models developed by Anthropic for tasks including writing, reasoning, coding, document analysis, and tool-assisted workflows.

FAST WORKFLOWS

Haiku

Designed for speed and responsiveness. Useful for simple tasks and high-volume applications.

BALANCED

Sonnet

A balance of capability, speed, and cost for everyday coding and knowledge work.

COMPLEX TASKS

Opus

The high-capability tier for demanding reasoning, coding, and complex analysis.

Key capabilities

  • Text generation and summarization
  • Code generation, debugging, and review
  • Document and image analysis where supported
  • Reasoning and complex problem-solving
  • Tool use and agent workflows

Model names, availability, and capabilities change over time. Check Anthropic's official documentation for current offerings.
