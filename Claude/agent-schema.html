Defining Tools and Schemas

Tools allow Claude to interact with external functions.

Example: Weather Tool

{
  "name": "get_weather",
  "description": "Get weather for a city",
  "input_schema": {
    "type": "object",
    "properties": {
      "city": {
        "type": "string",
        "description": "City name"
      }
    },
    "required": ["city"]
  }
}

Key Concepts

  • Name: Unique tool identifier.
  • Description: Explains when to use the tool.
  • Properties: Define input fields and data types.
  • Required: Lists mandatory fields.

Best practice: use clear descriptions and validate inputs.
