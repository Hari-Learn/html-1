🔌 Claude API Concepts

Request • Messages • Parameters • Response

1. What is an API?

An API allows your application to communicate with Claude programmatically.

Your App → Claude API → Claude Model → Response

2. Basic Messages API Request

model + max_tokens + messages

The request specifies which model to use, the output limit, and the conversation content.

3. Message Roles

System
Defines behavior and instructions.
User
Provides the task or input.
Assistant
Represents model output.

4. API Flow

Request → Authentication → Model Processing → Response

5. Important API Features

  • Tool use / function calling
  • Streaming responses
  • Structured outputs
  • Thinking / effort
  • Prompt caching
  • Batch processing
🧠 Remember: API = Application ↔ Claude communication.
