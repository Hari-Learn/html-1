Claude: Programmatic Tool Calling

Rare Topic 26 | CCAO-F Notes

1. What is it?

Claude writes code that calls your application tools from inside a Code Execution container.

Instead of asking Claude to handle every tool result separately, code can process several results first.

2. Traditional approach

Claude calls Tool A
Result goes back to Claude
Claude calls Tool B
Result goes back to Claude
Claude calls Tool C

3. Programmatic approach

Claude writes one script
↓
Script calls A, B and C
↓
Code filters and combines results
↓
Claude receives final output

4. Important setting

"allowed_callers": [ "code_execution_20260120" ]

This is an illustrative supported tool configuration. Check model and tool-version compatibility.

5. Why use it?

  • Reduce repeated model round trips.
  • Filter large tool results before they enter model context.
  • Run loops and conditional operations.
  • Reduce unnecessary input tokens in suitable workflows.

ELI10 Example

A manager asks you to check 20 employee expense records. Instead of bringing each record to the manager one by one, you check all 20, filter the exceptions and show only the employees who exceeded their budget.

6. When is it NOT ideal?

When each tool result requires Claude to think and decide what to do next, separate model round trips may be necessary. It may also add overhead for very small tasks.

Exam Scenario

An agent must query 50 customer records, filter inactive customers and return only a summary. The developer wants fewer model round trips. What should be considered?

Reveal answer

Programmatic Tool Calling, because the script can call tools repeatedly and filter results before returning the final output to Claude.
