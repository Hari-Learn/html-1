Example Prompt

You are a technical tutor.

Task: Explain REST APIs.
Audience: Beginners.
Format: 5 bullet points.
Limit: Under 100 words.
Include one practical example.

Best Practices

  • Put the main task in clear language.
  • Provide relevant context and reference data.
  • Ask for structured output when needed.
  • Test prompts against multiple examples.
  • Evaluate accuracy, consistency, and relevance.

Practice: Write a prompt that summarizes a document in 5 bullet points.
