MODULE 03

Hooks, Permissions & Subagents

Control execution, improve security and delegate development tasks.

1. Hooks

Hooks are event-driven automation mechanisms that execute configured actions when specific Claude Code events occur.

Common Hook Events

  • PreToolUse
  • PostToolUse
  • UserPromptSubmit
  • Stop
  • SessionStart
  • SessionEnd

Example use cases

{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Write|Edit",
        "hooks": [
          {
            "type": "command",
            "command": "npm run lint"
          }
        ]
      }
    ]
  }
}

2. Permissions

Permissions control which tools and operations Claude Code can execute automatically or only after approval.

Permission Categories

  • Allow – permit specific operations.
  • Ask – request user approval.
  • Deny – block specific operations.
{
  "permissions": {
    "allow": ["Read"],
    "ask": ["Bash"],
    "deny": ["Bash(rm -rf *)"]
  }
}

Illustrative permission policy; configure using Claude Code's supported settings schema.

3. Subagents

Subagents are specialized Claude Code agents that can handle delegated tasks with their own instructions, tools and context.

Example folder structure

.claude/
└── agents/
    ├── code-reviewer.md
    ├── tester.md
    └── researcher.md

Example: code-reviewer.md

---
name: code-reviewer
description: Reviews code for bugs and quality.
tools: Read, Grep, Glob
---

You are a code review specialist.

1. Inspect the codebase.
2. Identify potential bugs.
3. Check code quality.
4. Report security concerns.
5. Suggest improvements.

Practical Exercise

Create a hook that runs linting after code edits, configure permissions for shell commands, and create a code-reviewer subagent.
