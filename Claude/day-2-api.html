1. Thinking / Effort

Claude can use additional reasoning effort for tasks that benefit from deeper analysis.

Simple Task

Ordinary generation may be sufficient.

Complex Task

More reasoning can help with difficult problems.

Trade-off

Additional reasoning can affect latency and token usage.

2. Prompt Caching

Prompt caching allows eligible repeated prompt content to be reused rather than repeatedly processing the same large context.

Good candidates

  • • Large documents
  • • Stable instructions
  • • Shared context
  • • Repeated workflows

Key idea

Keep stable content cacheable and separate frequently changing content when appropriate.

6. Structured Outputs / JSON

Structured outputs make model responses easier for software to consume by following a predictable structure. 

{
  "name": "Hari",
  "score": 92,
  "passed": true
}
Predictable

Easier for applications to process.

Machine-readable

Useful for APIs and automation.

Less ambiguity

Reduces unpredictable formatting.

Exam concept: Structured output is especially useful when Claude's response will be consumed by another program.
