Claude: Thinking Blocks & Signatures

Rare Topic 27 | CCAO-F Notes

1. What is a thinking block?

When thinking is enabled, Claude's API response can contain a separate block of thinking-related content before the final text response.

It is a distinct content block, not ordinary user-facing answer text.

2. What is a signature?

A signature is an opaque, encrypted value associated with a thinking block.

It helps the API verify and preserve the thinking block when it is sent back in a continuing conversation.

3. Important block types

  • thinking — thinking-related content.
  • redacted_thinking — encrypted, safety-redacted thinking content.
  • text — normal response text.
  • tool_use — a tool call.

4. The critical rule

When continuing a tool-use conversation, pass the relevant thinking blocks back exactly as received.

Do not edit, rearrange or partially rebuild them.

5. What can go wrong?

Suppose application code keeps only blocks where type == "thinking" and drops redacted_thinking.

The conversation may fail with a 400 invalid request error because required blocks were modified or omitted.

6. Correct handling

  • Preserve the complete relevant block.
  • Keep its signature unchanged.
  • Keep redacted thinking blocks too.
  • Return the original assistant content sequence.

7. What NOT to do

  • Do not decode the signature.
  • Do not invent a signature.
  • Do not rewrite the thinking block.
  • Do not filter out required blocks.

ELI10 Example

Imagine a sealed envelope with a security seal. You need to send it to another person. You must pass the envelope and seal along unchanged. You should not open it, modify it or replace the seal.

Exam Scenario

An application uses Claude with thinking and tools. Its code removes all redacted_thinking blocks before sending the previous assistant response back. The API returns a 400 error. What is the likely fix?

Reveal answer

Preserve and return the relevant thinking and redacted_thinking blocks unchanged, including their associated signatures or encrypted data.
