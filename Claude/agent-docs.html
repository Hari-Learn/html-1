MODULE 02 / LESSON 01

Uploading Documents & Files

Learn how to upload files and use Claude to understand, analyze and summarize documents.

What You Will Learn

  • How to upload documents to Claude.
  • Supported file formats.
  • Reading and summarizing PDF files.
  • Extracting information from documents.
  • Comparing multiple files.
  • Asking questions about uploaded files.

1. How to Upload a Document

Open a Claude conversation and use the attachment button to select a file from your device. Wait for the upload to finish before sending your question.

Example Prompt

"Read this PDF and provide a summary of its main points. Organize the summary into headings and bullet points."

2. Common File Types

📄 PDF
📝 DOCX
📊 XLSX
📃 TXT
📋 CSV
📑 PPTX*

*File support depends on the current Claude interface and plan. Check the upload options for supported formats.

3. Practical Examples

  1. Upload a resume and ask Claude to improve its wording.
  2. Upload a business report and request a summary.
  3. Upload an Excel file and ask for trends in the data.
  4. Upload two documents and compare their contents.
  5. Upload a study material PDF and generate quiz questions.

4. Best Practices

  • Use clear and specific instructions.
  • Upload readable documents.
  • Ask one task at a time for complex files.
  • Verify important numbers and facts.
  • Avoid uploading confidential information unnecessarily.
