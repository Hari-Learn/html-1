What are Guardrails?

Guardrails are rules and controls that limit unsafe behavior, enforce requirements, and keep AI outputs within acceptable boundaries.

Core Concepts

Input Validation

Check input types, lengths, formats, and allowed values.

Output Validation

Verify responses against schemas and business rules.

Safety Filters

Detect harmful requests and sensitive information.

Human Approval

Require review before high-impact actions.

Validation Workflow

User Input → Validate → Claude API → Validate Output → Return Response
