MODULE 02 / LESSON 03

Voice Features & Chat History

Learn how to interact with Claude using voice and organize your conversations effectively.

Learning Objectives

  • Understanding voice interaction.
  • Using voice input where available.
  • Speaking naturally with Claude.
  • Managing conversation history.
  • Searching and organizing conversations.
  • Deleting and archiving chats where supported.

Part A: Working with Voice

Voice features allow users to interact with Claude through spoken language, depending on the device, app and available features.

Example Voice Instruction

"Explain artificial intelligence in simple English with three practical examples."

Voice Interaction Steps

  1. Open Claude on a supported device.
  2. Find the available voice or microphone control.
  3. Allow microphone permission if requested.
  4. Speak your question clearly.
  5. Listen to the response if voice output is available.
  6. Continue the conversation naturally.

Voice Use Cases

  • Language learning and speaking practice.
  • Hands-free brainstorming.
  • Learning new subjects.
  • Dictating notes and ideas.
  • Asking questions while multitasking.

Part B: Managing Chat History

Chat history helps you revisit previous discussions, continue projects and keep conversations organized.

Important Features

Conversation History

Access previous conversations from your chat list.

Search Conversations

Find older discussions using available search features.

Rename Chats

Give conversations meaningful titles when supported.

Delete Conversations

Remove conversations you no longer need.

Organizing Your Chat History

  1. Use descriptive titles for conversations.
  2. Create separate projects for different subjects.
  3. Keep related discussions together.
  4. Review old conversations periodically.
  5. Delete sensitive conversations when appropriate.
  6. Check data retention and privacy settings.

Practice Exercise

Try the following activities:

  • Start a voice conversation with Claude, if available.
  • Ask Claude to explain a technical topic.
  • Start a new conversation about another subject.
  • Find an earlier conversation.
  • Rename or delete a test conversation.

Module Summary

You have learned how to use voice interactions, manage conversations, organize chat history and improve your overall Claude experience.
