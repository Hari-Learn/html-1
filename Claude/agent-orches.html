Agent Orchestration Patterns

How multiple steps or agents work together

1. Sequential Workflow

Each step waits for the previous step to finish.

A → B → C

Example: Collect data → Analyse → Generate report.

Use when steps depend on each other.

2. Parallel Workflow

Independent tasks run simultaneously.

A + B + C → Combine

Example: Analyse sales, expenses and inventory at the same time.

Use when tasks don't depend on each other.

3. Routing Pattern

A router decides which specialist or workflow should handle the request.

Example: Billing request → Billing agent.

Technical issue → Technical support agent.

4. Supervisor Pattern

One central agent coordinates several specialist agents.

Supervisor → Researcher, Writer, Reviewer.

The supervisor assigns tasks and combines results.

5. Evaluator–Optimizer

One agent produces an output. Another evaluates it and gives feedback.

Generate → Evaluate → Improve → Repeat.

Example: Draft an answer, check quality, rewrite if necessary.

Avoid Overengineering

Do not create multiple agents for every task.

A single agent with good tools may be simpler, cheaper and easier to maintain.

Exam Insight

Independent work → Parallel. Dependency → Sequential. Different request types → Routing. Multiple specialists coordinated → Supervisor.
