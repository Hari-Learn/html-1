CLAUDE API · LESSON 03

Inputs & Responses

Send text or documents and process Claude's output.

1. Send text input

response = client.messages.create(
    model="claude-sonnet-4-5",
    max_tokens=300,
    messages=[{
        "role": "user",
        "content": "Summarize: AI helps automate tasks."
    }]
)

print(response.content[0].text)

2. Send a PDF document

import base64

with open("document.pdf", "rb") as file:
    pdf_data = base64.b64encode(file.read()).decode("utf-8")

response = client.messages.create(
    model="claude-sonnet-4-5",
    max_tokens=500,
    messages=[{
        "role": "user",
        "content": [
            {
                "type": "document",
                "source": {
                    "type": "base64",
                    "media_type": "application/pdf",
                    "data": pdf_data
                }
            },
            {"type": "text", "text": "Summarize this PDF."}
        ]
    }]
)

3. Handle the response

for block in response.content:
    if block.type == "text":
        print(block.text)

print("Stop reason:", response.stop_reason)
print("Input tokens:", response.usage.input_tokens)
print("Output tokens:", response.usage.output_tokens)

Remember

Handle API errors, validate inputs, protect sensitive documents, and check token usage. PDF support and size limits depend on the API's current documentation.
