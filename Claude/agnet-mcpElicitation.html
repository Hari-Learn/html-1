MCP Elicitation

How an MCP server requests additional information

What Is Elicitation?

Elicitation allows an MCP server to request information from the user through the client.

Think of it as asking a clarification question before continuing.

Example

User: "Book a table for me."

Server needs more information:

  • Which date?
  • How many people?
  • What time?

Elicitation Flow

Server → Client → User → Client → Server

The server pauses its workflow while the client obtains the requested information.

Why Is It Useful?

  • Avoids guessing missing information
  • Supports interactive workflows
  • Improves input completeness
  • Reduces invalid tool calls

User Control

The user may provide the information, decline or cancel.

The server must handle these outcomes safely.

Important Limitation

Elicitation requires client support.

It is not permission to collect passwords, secret keys or other sensitive credentials through an ordinary form.

Exam Insight

When a workflow needs missing user input, elicitation can request it instead of allowing the agent to invent values. Check whether the client supports this capability.
