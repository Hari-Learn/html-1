CLAUDE API · LESSON 02

System Prompts & Roles

Control Claude's behavior and structure conversations.

System prompt

Defines instructions, expertise, tone, and constraints.

User role

Contains the question, task, or input from the user.

Example using Python

import anthropic

client = anthropic.Anthropic()

response = client.messages.create(
    model="claude-sonnet-4-5",
    max_tokens=200,
    system="You are a friendly Python tutor. Use simple examples.",
    messages=[
        {
            "role": "user",
            "content": "Explain Python variables."
        }
    ]
)

print(response.content[0].text)

Key concepts

  • The system parameter provides high-level instructions.
  • The user role supplies the task or question.
  • The assistant role represents Claude's replies in conversation history.
  • Keep instructions clear, specific, and consistent.
