Model Selection

Choosing the right Claude model and balancing quality, speed and cost.

1. Why Model Selection Matters

Different models have different capabilities, response speeds and costs.

ELI10: You don't need a specialist for every small job. Choose the right tool for the task.

2. Claude Model Families

Haiku

Designed for fast, efficient tasks such as classification and simple extraction.

Sonnet

A balanced choice for many everyday business and coding tasks.

Opus

Designed for demanding tasks requiring advanced reasoning and capabilities.

Exact capabilities, names and pricing vary by model generation.

3. Thinking / Extended Thinking

For supported models, extended thinking allows Claude to spend additional effort reasoning through complex problems before answering.

Useful for:

  • Complex mathematical problems
  • Multi-step analysis
  • Difficult coding tasks
  • Complicated planning and reasoning

More thinking effort can increase latency and token usage.

4. Cost Optimisation Strategies

  • Use an appropriate smaller model for simple tasks.
  • Use a more capable model when task complexity justifies it.
  • Keep prompts focused and avoid unnecessary tokens.
  • Use prompt caching for repeated shared context.
  • Use batch processing for suitable non-urgent workloads.
  • Measure quality, latency and cost before changing models.

5. Model Selection Examples

Classify one million simple support messages → Consider Haiku.

Analyse a complex business strategy → Consider Opus.

Handle everyday document drafting → Consider Sonnet.

6. Exam Scenario

A company uses a powerful model for every simple classification request. The system is expensive. What should the team do?

Reveal answer

Evaluate a smaller, faster model on representative examples. Switch only if it meets the required accuracy and quality.

Remember: Choose based on task complexity, quality, latency and cost.
