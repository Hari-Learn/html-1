Vision & Document Understanding

Using images and documents as input to Claude.

1. What is Vision?

Vision allows supported Claude models to analyse visual information in images.

ELI10: You show Claude a photograph and ask it what is happening in the picture.

2. Common Use Cases

  • Read text from screenshots.
  • Analyse charts and diagrams.
  • Understand product photographs.
  • Inspect forms and scanned documents.
  • Extract information from supported visual inputs.

3. PDF Understanding

For supported Claude models and API configurations, PDF processing can use both extracted text and page images.

PDF example

A company uploads a financial report containing:

  • Written paragraphs
  • Tables
  • Charts
  • Scanned pages

Claude can analyse supported text and visual content together.

4. Important Considerations

  • Image resolution affects what can be recognised.
  • Small text may be difficult to read.
  • Complex tables and charts need careful verification.
  • Supported image formats and PDF limits depend on the API.
  • Never assume every visual detail is interpreted correctly.

5. Exam Scenario

A user uploads a screenshot of a sales dashboard and asks Claude to explain the trend shown in its chart. Which capability is required?

Reveal answer

Vision capability. Claude analyses the image and interprets the chart, while the application should verify important numerical conclusions.

Remember: Vision interprets images; PDF processing can combine text and visual understanding.
