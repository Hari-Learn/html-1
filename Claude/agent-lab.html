PERFORMANCE / 002

Prompt caching

Prompt caching can reuse eligible portions of a repeated prompt instead of processing the same prefix from scratch each time. Depending on the API, this can reduce latency and input costs.

CONTEXT / 003

Context engineering

Context engineering is the practice of deciding what information, instructions, tools, and examples an AI system should receive. More context is not automatically better.

  • ✓ Keep instructions clear and consistent.
  • ✓ Retrieve relevant documents instead of dumping everything.
  • ✓ Separate trusted reference data from untrusted input.
  • ✓ Test whether additional context improves results.
