CLAUDE API · LESSON 05

Long-Context Handling

Work effectively with large documents and lengthy conversations.

Core Strategies

  • Organize: Divide documents into logical sections.
  • Prioritize: Place key instructions and questions clearly.
  • Filter: Include only context relevant to the task.
  • Summarize: Create concise notes from earlier conversations.
  • Verify: Ask for evidence from the supplied source.

Example with Python

import anthropic

client = anthropic.Anthropic()

with open("report.txt", encoding="utf-8") as f:
    document = f.read()

response = client.messages.create(
    model="claude-sonnet-4-5",
    max_tokens=500,
    messages=[{
        "role": "user",
        "content": f"""
        Analyze this report.
        Summarize key findings and risks.
        Cite relevant sections where possible.
        
        {document}
        
        """
    }]
)

print(response.content[0].text)

Important

Check the model's context window and output-token limits. Large files may require chunking, retrieval, or staged analysis.

Practice: Extract decisions, risks, and action items from a long report.
