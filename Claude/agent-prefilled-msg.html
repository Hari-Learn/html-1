Claude API: Prefilled Messages

Rare Topic 19 | CCAO-F Notes

1. What is prefill?

A prefilled assistant message is a partial assistant response supplied by the application.

Example: the conversation ends with an assistant message beginning with:

{"role":"assistant","content":"{ \"answer\": "}

2. Why was it used?

  • Encourage a specific output format.
  • Start a response with a required phrase.
  • Continue a partially written structure.

Think of it as giving Claude the first few words of its answer.

3. Important model change

Anthropic documents that final-turn assistant prefills are not supported on Claude 4.6 and later models covered by its migration guidance.

A request using an unsupported prefill can return a 400 error.

4. Better alternatives

  • Use clear system instructions.
  • Describe the required output format.
  • Use structured outputs when suitable.
  • Validate the returned data in your application.

ELI10 Example

Old method: You give a student the beginning of a sentence and ask them to finish it.

New method: You tell the student exactly what format to follow, without supplying a partial answer.

Exam Scenario

An application uses a partial assistant message to force JSON output. After changing to a newer Claude model, the API returns a 400 error. What should the developer do?

Reveal answer

Remove the unsupported final-turn prefill and use an appropriate output-format instruction or structured output feature.
