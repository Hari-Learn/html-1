Claude API Stop Reasons

Understanding why a response ends

1. What is stop_reason?

The stop_reason field tells your application why Claude stopped generating a message.

ELI10: It is like knowing why a student stopped writing an answer.

2. Important Stop Reasons

end_turn

Claude completed its response normally.

max_tokens

The response reached its output token limit.

tool_use

Claude is handing control to a tool.

stop_sequence

A configured stop sequence was encountered.

3. Message Lifecycle

Application sends request
↓
Claude generates message
↓
API returns stop_reason
↓
Application decides next action

4. Why It Matters

  • Know whether Claude finished normally.
  • Detect responses cut short by token limits.
  • Recognise when a tool must be executed.
  • Build reliable agent workflows.

5. Exam Scenario

Claude returns stop_reason as tool_use. What should the application do?

Reveal answer

Execute the requested tool, return its result to Claude and continue the conversation.

6. Quick Revision

end_turn = finished

max_tokens = output limit reached

tool_use = tool handoff

stop_sequence = configured stopping text found
