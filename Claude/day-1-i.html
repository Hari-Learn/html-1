DAY 1 • FOUNDATIONS

Claude & Prompting Foundations

Core concepts for writing clear, useful prompts.

What is Claude?

Claude is an AI assistant/model family from Anthropic. You provide instructions and context, and it generates responses based on that input.

Task

The task is the specific outcome you want: summarize, classify, explain, extract, transform, generate, or analyze.

Context

Relevant background information that helps Claude understand the situation, data, audience, and purpose.

Constraints

Rules that limit the output, such as length, format, tone, required fields, exclusions, or source requirements.

Roles

A role frames the perspective or responsibility: tutor, reviewer, analyst, developer, technical writer, and so on.

Clear vs Vague

Vague: "Write about APIs."
Clear: "Explain REST APIs to a beginner in 5 bullets with one example."

Zero-Shot Prompting

Give the task without examples. The model must follow the instruction directly.

Few-Shot Prompting

Give a few input → output examples so the model can learn the expected pattern, style, or classification.

System vs User Instruction

System instructions define higher-level behavior and rules. User instructions specify the requested task within those rules.

Prompt Template

Reusable prompt structure with variables:
Task: {task}
Context: {context}
Output: {format}
