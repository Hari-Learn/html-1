Context Management

How to manage large conversations and documents effectively.

1. What is Context?

Context is the information available to Claude when generating a response.

ELI10: Context is like the contents of your school bag. Claude can use what is inside the bag.

2. Context Window

The context window is the maximum amount of information the model can process in a request.

Context window capacity Illustration

Used context + available capacity

The actual limit depends on the Claude model and configuration.

3. What Uses Context?

  • System instructions
  • User messages
  • Conversation history
  • Documents and images supplied to the model
  • Tool results
  • Other content included in the request

4. Managing Long Conversations

  • Remove irrelevant conversation history where appropriate.
  • Summarise older discussions.
  • Retrieve only relevant document sections.
  • Keep instructions concise and clear.
  • Use retrieval systems for large knowledge bases.

Goal: Give Claude the relevant information without unnecessary content.

5. Retrieval vs Full Document Input

Full document

Send the entire document when broad context is needed and it fits.

Retrieval

Find and send only relevant sections when the knowledge base is large.

6. Exam Scenario

A company has thousands of pages of policy documents. Each question needs only a few relevant paragraphs. What is a sensible approach?

Reveal answer

Use retrieval to find relevant passages and include those passages in Claude's context.

Remember: Context window = capacity. Context = information supplied.
