Working with Claude Code

1. Terminal Basics

Learn essential command-line operations.

pwd
ls
cd my-project
mkdir new-project

2. Existing Codebases

Open an existing project and ask Claude to understand its structure.

cd existing-project
claude

Example prompt:

"Analyze this project and explain its architecture, files and dependencies."

3. Create Projects from Scratch

Create a new application using Claude Code.

mkdir my-app
cd my-app
claude

"Create a responsive website using HTML, CSS and JavaScript."
