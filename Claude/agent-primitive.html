MCP Primitives

Resources, Tools and Prompts

1. What are MCP Primitives?

MCP defines standard ways for servers to expose information and functionality to AI applications.

ELI10: An MCP server can provide information, perform actions and offer reusable instructions.

2. Three Core Primitives

Resources

Provide data or context.

Example: Company policy document.

Tools

Perform actions.

Example: Create a calendar event.

Prompts

Provide reusable templates.

Example: Meeting summary template.

3. Who Controls Them?

Resources

Generally application-controlled: the client decides which resources to include.

Tools

Model-controlled: the model can request an available tool, subject to application rules.

Prompts

User-controlled: users can select or invoke reusable prompt templates.

4. Simple Example

Imagine a company HR MCP server.

  • Resource: Employee handbook.
  • Tool: Submit leave application.
  • Prompt: Prepare an employee leave summary.

5. Exam Scenario

An MCP server exposes a company handbook as readable information. Which primitive is appropriate?

Reveal answer

Resources, because the handbook provides information rather than performing an action.

6. Quick Revision

Resources = Read information

Tools = Perform actions

Prompts = Reusable instructions
