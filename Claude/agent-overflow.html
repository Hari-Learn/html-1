Context Window Management

What happens when a conversation becomes too large?

Context Window

Think of it as a bucket.

The bucket has limited capacity. Every message, document and tool result consumes space.

When the available capacity is insufficient, the request cannot fit.

Signs of Overflow

  • Input exceeds context limit
  • Very long conversation history
  • Large tool outputs
  • Huge documents or retrieved content

Strategy 1: Summarization

Convert old conversation history into a shorter summary.

Keep important decisions, facts and pending tasks.

Replace unnecessary older details with the summary.

Strategy 2: Truncation

Remove less important content.

Example: Remove old irrelevant messages or duplicate tool results.

Warning: Important information may be lost.

Strategy 3: Retrieval

Store information outside the active context.

Retrieve only the relevant information when needed.

Example: Search a document store instead of loading every document.

Strategy 4: Compact Tool Results

Avoid placing huge tool outputs into the conversation.

Filter, summarise or select only relevant fields.

Exam Insight

If context is too large, don't blindly remove everything. Preserve important instructions, decisions and task state; summarise or retrieve information selectively.
