What are tokens?

Tokens are units of data processed by language models. A token may represent a word, part of a word, punctuation, or another piece of text.

Example sentence

Claude can explain AI.

Tokenization varies by model.

Context window

The context window is the amount of input and conversation context a model can process in a request. Limits vary by model.
