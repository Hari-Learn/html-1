Claude: Server-Side Web Search

Rare Topic 20 | CCAO-F Notes

1. What is it?

A built-in tool that lets Claude search the web for current information.

Useful when a question needs information beyond the model's existing knowledge.

2. When is it useful?

  • Latest news and announcements.
  • Current product information.
  • Recent company updates.
  • Information that may have changed.

3. How does it work?

1. User asks a question.
↓
2. Claude decides to search.
↓
3. Search tool returns results.
↓
4. Claude prepares an answer with citations.

4. Important controls

  • max_uses limits searches per request.
  • allowed_domains restricts sources.
  • blocked_domains excludes selected sources.
  • Domain allowlist and blocklist are alternatives, not combined settings.

5. Citations matter

Search results can provide source information that Claude uses to attach citations to parts of its answer.

Your application should preserve and display those citations so users can inspect the sources.

ELI10: Who does the searching?

Think of Claude as a researcher. You give it a question, it asks the built-in librarian to find sources, then it explains what it found.

Your application does not need to write its own search execution code for this server-side tool.

Exam Scenario

A company wants Claude to search only its approved websites. Which setting should it configure?

Reveal answer

allowed_domains. It restricts search results to the specified domains.
