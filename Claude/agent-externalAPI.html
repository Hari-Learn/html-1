Connecting External APIs

Integrate Claude with external services through your backend.

Example API Request

async function getUser(userId) {
  const response = await fetch(
    `https://api.example.com/users/${encodeURIComponent(userId)}`,
    {
      headers: {
        Authorization: `Bearer ${process.env.API_KEY}`
      }
    }
  );

  if (!response.ok) {
    throw new Error("API request failed");
  }

  return response.json();
}

Integration Workflow

  1. Define a Claude tool schema.
  2. Receive a tool-use request.
  3. Validate the arguments.
  4. Call the external API from your backend.
  5. Return the API result to Claude.
  6. Generate the final response.

Security: keep API keys on the server, never in browser code.
