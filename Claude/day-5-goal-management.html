8. Cost & Latency Optimization

Make agents cheaper and faster without unnecessarily reducing quality.

Cost
Use fewer tokens/tools.
Latency
Parallelize independent tasks.
Model
Use the right model for each task.

9. Human Approval Thresholds

Define which actions require human approval.

Low risk → Agent acts
Medium risk → Agent asks approval
High risk → Human must approve

10. Agent Identity

Identity defines who the agent is and what authority it operates with.

Includes: agent ID, role, credentials, permissions and audit identity.

11. Agent Recovery

Recovery allows an agent to continue safely after failure.

Failure → Detect → Save State → Retry / Rollback → Resume

12. Goal Management

Agents must maintain the correct goal while executing multiple steps.

  • Keep the original objective.
  • Track progress.
  • Prioritize sub-goals.
  • Detect goal drift.
  • Stop when the goal is satisfied.
🧠 Exam Memory: Optimize → Approve → Identify → Recover → Manage Goals.
