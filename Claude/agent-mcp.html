Tool Use, MCP & Security

How Claude connects with external systems.

1. Tool Use Loop

User Task
Claude Request
Tool Execution
Tool Result

Claude requests a tool call. Your application executes it and sends the result back to Claude.

Important: A tool request does not mean the action succeeded.

2. Model Context Protocol (MCP)

MCP is an open protocol that connects AI applications to external tools and data sources.

Host

AI application, such as Claude Desktop.

Client

Connection component inside the host.

Server

Exposes tools, resources and prompts.

3. Security & Guardrails

  • Validate tool inputs.
  • Use minimum required permissions.
  • Require human approval for sensitive actions.
  • Treat external tool results as untrusted data.
  • Protect credentials and API keys.
  • Log important actions.

Exam Scenario

Claude proposes transferring money. Should the application execute immediately?

Reveal Answer

No. Validate permissions and require appropriate human approval before execution.

Remember: Claude requests. The application controls execution.
