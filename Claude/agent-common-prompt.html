Common Prompting Mistakes

Learn to identify weak prompts and make them effective.

01. Being too vague

Bad: Tell me about business.

Better: Explain five steps to start an online business with a small budget.

02. Missing context

Bad: Write an email.

Better: Write a polite follow-up email to a client about an overdue invoice.

03. No output format

Bad: Compare these products.

Better: Compare these products in a table with price, features, and limitations.

04. Too many conflicting instructions

Avoid asking for exhaustive detail and extreme brevity at the same time. Prioritize your requirements.

05. Not checking the response

Verify important facts, calculations, sources, and assumptions before using the output.

Prompt checklist

  • Is the goal specific?
  • Have I provided enough context?
  • Have I defined the output format?
  • Are the instructions consistent?
  • Have I reviewed the final answer?
