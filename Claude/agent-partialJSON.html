Streaming Events

Understanding real-time API responses

1. What is Streaming?

Streaming allows an application to receive Claude's response progressively instead of waiting for the complete message.

ELI10: Like watching someone type a message instead of receiving the whole message at once.

2. Important Events

message_start

A new message begins.

content_block_start

A content block begins.

content_block_delta

A piece of content arrives.

content_block_stop

A content block ends.

message_delta

Message-level information is updated.

message_stop

The message stream ends.

3. Streaming Flow

Message starts
↓
Content blocks arrive
↓
Content deltas arrive progressively
↓
Message stops

4. Partial JSON

When Claude streams structured output, JSON may arrive in incomplete pieces.

{"name":
"Ravi",
"age": 30}

Do not assume each incoming chunk is a complete valid JSON object. Assemble the content before parsing.

5. Why Streaming Matters

  • Improves perceived response speed.
  • Displays text progressively.
  • Supports responsive user interfaces.
  • Allows applications to process events as they arrive.

6. Exam Scenario

A developer parses every streaming chunk as a complete JSON object. The parser frequently fails. What is the problem?

Reveal answer

Chunks can contain partial JSON. Accumulate the relevant content and parse it when the complete structured output is available.

7. Quick Revision
