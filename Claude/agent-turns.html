Agent Loops & Termination

How an agent decides when to continue or stop

Agent Loop

An agent repeatedly thinks, acts, observes and decides.

  • Understand the task
  • Choose an action or tool
  • Observe the result
  • Decide the next step

When Does It Stop?

The agent stops when:

  • Task is completed
  • It cannot make progress
  • Human intervention is needed
  • A safety boundary is reached
  • Maximum turns or limits are reached

Max Turns

A limit on how many agent steps or turns can occur.

Purpose: Prevent endless loops, excess cost and delays.

If reached, the agent should stop safely or return control.

Example

Agent tries to find an order 10 times but fails.

Instead of retrying forever, it stops and escalates.

Exam Insight

When an agent keeps repeating actions, consider termination conditions, max-turn limits and loop prevention.
