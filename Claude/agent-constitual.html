Constitutional AI

How principles help guide model behaviour.

1. What is Constitutional AI?

Constitutional AI is an approach developed by Anthropic to train AI systems using a set of guiding principles.

ELI10: Like giving a student a rulebook to help decide what is right and wrong.

2. How Does It Work?

Generate an initial response

↓

Evaluate against guiding principles

↓

Revise problematic content

↓

Improve the response

3. Important Principles

  • Helpfulness: provide useful assistance.
  • Harmlessness: avoid enabling harm.
  • Honesty: avoid misleading claims.
  • Respect: respond appropriately to people.

4. Critique and Revision

A model can review its own draft against a set of principles and produce a revised response.

Important: This is a training approach, not a guarantee that every answer will be safe or correct.

5. Exam Scenario

A team wants to improve model behaviour by training it to critique responses against written principles. Which approach is relevant?

Reveal answer

Constitutional AI: using explicit principles to guide critique and revision during model training.

Remember: Constitutional AI = principles-guided model training.
