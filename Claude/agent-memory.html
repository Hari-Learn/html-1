Claude Styles and Memory

1. What are Claude Styles?

Styles allow users to customize how Claude communicates, writes, and formats responses.

2. Common Writing Styles

  • Professional and formal.
  • Friendly and conversational.
  • Concise and direct.
  • Explanatory and educational.
  • Custom writing styles.

3. Creating Custom Styles

  1. Open Claude settings.
  2. Navigate to Styles.
  3. Select or create a style.
  4. Define writing preferences.
  5. Save your configuration.
  6. Use the style in conversations.

4. What is Claude Memory?

Memory helps Claude retain relevant information about your preferences and ongoing work, where memory features are available and enabled.

5. Memory Examples

  • Preferred response language.
  • Preferred explanation level.
  • Writing and formatting preferences.
  • Relevant project context.
  • Recurring work preferences.

6. Example Custom Instruction

Prompt

Always explain technical topics using simple English, step-by-step instructions, and practical examples.

7. Practice Task

Create a friendly educational writing style and explore Claude's available memory settings.
