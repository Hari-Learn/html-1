CLAUDE API · LESSON 01

Your First API Request

Connect your application to Claude using the Anthropic API.

Prerequisites

  • An Anthropic Console account
  • An API key with access to a model
  • Python and the Anthropic SDK

1. Install the SDK

pip install anthropic

2. Send a request

import anthropic

client = anthropic.Anthropic()

response = client.messages.create(
    model="claude-sonnet-4-5",
    max_tokens=200,
    messages=[
        {"role": "user", "content": "Explain AI simply."}
    ]
)

print(response.content[0].text)

Important

Set ANTHROPIC_API_KEY as an environment variable. Never expose your API key in browser JavaScript.

Learning outcome: Make a request and display Claude's response.
