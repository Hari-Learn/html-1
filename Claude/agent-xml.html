XML Tags & Prompt Organization

Structure instructions, context, examples, and output requirements.

Example prompt

<role>You are a helpful tutor.</role>
<context>The learner is a beginner.</context>
<task>Explain machine learning.</task>
<constraints>Use simple language and 3 examples.</constraints>
<output_format>Use headings and bullet points.</output_format>

Why XML tags?

Separate instructions from context and examples.

Best practices

Use descriptive tags, consistent structure, and explicit output formats.
