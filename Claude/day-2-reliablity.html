2. Error Handling & Retries

Production applications should handle API failures gracefully instead of assuming every request succeeds.

Handle

  • • Temporary API failures
  • • Rate-limit responses
  • • Network failures
  • • Invalid requests

Retry strategy

  • • Exponential backoff
  • • Random jitter
  • • Maximum retry count
  • • Logging and monitoring
Important: Do not blindly retry every error. Permanent request errors may require fixing the request instead.

4. API Security

API credentials are sensitive secrets and must be protected.

✅ Do

  • ✓ Store keys in environment variables.
  • ✓ Use a secret manager when appropriate.
  • ✓ Keep API calls on a trusted backend.
  • ✓ Rotate compromised credentials.
  • ✓ Restrict access where possible.

❌ Don't

  • ✗ Hard-code API keys.
  • ✗ Put keys in frontend JavaScript.
  • ✗ Commit secrets to Git.
  • ✗ Share keys in screenshots.
  • ✗ Expose production credentials publicly.
