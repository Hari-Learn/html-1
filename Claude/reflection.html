```html Agent Reflection
🔄 Agent Reflection

Reflection • Self-Correction • Improvement

What is Agent Reflection?

Reflection means the agent looks at its own work, identifies problems, and decides how to improve it.

Plan → Act → Check → Reflect → Correct → Continue

Self-Correction Example

1️⃣ Agent writes code.
2️⃣ Agent runs the tests.
3️⃣ Test fails → Agent identifies the mistake.
4️⃣ Agent changes the code.
5️⃣ Agent runs the test again.

Why Reflection is Useful

  • Find mistakes before finishing.
  • Improve the quality of results.
  • Recover from failed actions.
  • Compare the result with the original goal.
  • Reduce repeated mistakes.

Reflection vs Planning

Planning

“What should I do next?”

Reflection

“Did what I did actually work?”

🧠 Exam Memory: Reflection = Check your work.
Self-Correction = Find the mistake → Fix it → Try again.
```
