Prompt Injection

Prompt injection is an attack where malicious instructions attempt to manipulate an AI system into ignoring its intended rules.

Example Scenario

An AI assistant summarizes an uploaded document containing hidden instructions asking it to reveal confidential information.

Risk: Untrusted content manipulates AI behavior.

How to Prevent It

  • ✓ Treat external content as untrusted input.
  • ✓ Separate system instructions from user content.
  • ✓ Validate AI outputs before sensitive actions.
  • ✓ Limit AI access to tools and private data.
  • ✓ Require human approval for critical operations.

Key Takeaway

Never assume an AI model can reliably distinguish every malicious instruction from legitimate content.
