🧠 Claude & LLM Fundamentals

Quick CCAO-F Study Guide

1. What is an LLM?

LLM = Large Language Model. It learns patterns from large amounts of text and generates the most appropriate next tokens based on context.

Input → Tokens → Model Processing → Output

2. What is Claude?

Claude is an AI assistant developed by Anthropic. It uses large language models to understand instructions, reason over context, and generate responses.

3. Tokens

A token is a unit of text processed by an LLM. It can be a word, part of a word, punctuation, or other text unit.

More tokens = more context and potentially more processing cost.

4. Context Window

The context window is the amount of information the model can consider during a request.

Instructions + Conversation + Documents + Tool Results → Context

5. Training vs Inference

Training
Model learns patterns from training data.
Inference
Trained model generates an answer for a request.

6. Temperature

Temperature controls how much variation is allowed in generated output.

Lower → more predictable | Higher → more varied

7. Hallucination

A hallucination occurs when an LLM produces information that sounds correct but is inaccurate, unsupported, or invented.

Reduce risk with grounding, clear context, tools, validation, and verification.

8. Reasoning & Generation

An LLM processes the provided context and instructions to generate an output. Better instructions and relevant context can improve results.

🧠 Exam Memory

LLM = Language model | Token = Text unit | Context window = Information available to the model | Training = Learn | Inference = Generate | Temperature = Variation | Hallucination = Incorrect generated information
