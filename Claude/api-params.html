⚙️ Claude API Parameters

Know what each parameter controls

1. model

Specifies which Claude model should process the request.

model → "claude-sonnet-5"

2. max_tokens

Sets the maximum number of tokens the model can generate in the response.

Think: Output size limit

3. messages

Contains the conversation input, including user messages and their content.

messages → role + content

4. system

Provides high-level instructions that guide Claude's behavior.

system → "You are a helpful coding assistant."

5. thinking / effort

Controls how much reasoning effort Claude uses when supported by the model.

More effort can be useful for difficult reasoning tasks.

6. tools

Defines tools that Claude can use to perform actions or retrieve information.

Claude → Tool Call → Tool Result → Claude

7. stream

Allows the response to be delivered progressively instead of waiting for the complete response.

Useful for better perceived responsiveness.

8. Important Current Note

Older parameters such as temperature, top_p, and top_k are deprecated for newer Claude models. For current models, follow Anthropic's model-specific API documentation.

🧠 Exam Memory: model = which model | max_tokens = output limit | messages = conversation | system = behavior | thinking/effort = reasoning effort | tools = actions | stream = progressive response. Designed and Developed by Anthropic. Always refer to the latest API documentation for updates.
