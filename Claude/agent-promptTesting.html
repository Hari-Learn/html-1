CLAUDE AI · MODULE 03

Prompt Refinement & Testing

Improve prompts through measurable experiments.

Iterative workflow

  1. Define the task and success criteria.
  2. Test a baseline prompt.
  3. Inspect errors and missing details.
  4. Change one variable at a time.
  5. Compare results on multiple examples.
  6. Save the best-performing version.

Common mistakes

Vague goals, conflicting instructions, missing context, excessive constraints, no evaluation.

Best practices

Be specific, provide examples, define formats, test edge cases, verify facts.

Practice: Test two prompt versions on five representative inputs and compare accuracy and consistency.
