Structured Outputs

Making Claude return predictable, schema-based data.

1. What is it?

Structured outputs constrain Claude's response to follow a defined JSON Schema.

ELI10: Instead of asking someone to write freely, give them a form with fixed fields to fill.

2. Without vs With Schema

Without schema

Name: Ravi, maybe 30 years old. Email is...

Output may vary.

With schema

{
 "name": "Ravi",
 "age": 30,
 "email": "ravi@example.com"
}

3. How it works

  1. Developer defines a JSON Schema.
  2. Schema is sent through output_config.format.
  3. Claude generates schema-constrained output.
  4. Application reads and processes the JSON.

4. Important API Detail

The Messages API uses output_config.format with type: json_schema.

Do not confuse JSON outputs with strict tool use. JSON outputs constrain responses; strict tool use constrains tool names and inputs.

5. Exam Scenario

An application extracts customer details. Its JSON parser frequently fails because Claude returns inconsistent formats. What should developers use?

Reveal answer

Structured outputs with a JSON Schema to constrain the response format.

Remember: JSON Schema = predefined output structure.
