Agent Observability

Page 30 | Monitoring and evaluating production agents

1. Logging

Recording important events during agent execution.

Example: Tool called, response received, error occurred.

Never log passwords or sensitive data unnecessarily.

2. Metrics

Numerical measurements used to understand system performance.

Examples: Success rate, latency, token usage, cost and escalation rate.

3. Distributed Tracing

Tracks a request across multiple services and tools.

Example: Customer request → Claude → MCP tool → Payment backend.

Helps locate where delays or failures occur.

4. Latency

The time taken to complete a request.

High latency can result from slow tools, network delays or long model responses.

5. Evaluation

Testing whether the agent produces the expected result.

Evaluate accuracy, tool selection, policy compliance and response quality.

6. Regression Testing

Running previous tests after a change.

Ensures a new prompt or tool update does not break existing behaviour.

7. First Contact Resolution

Measures the percentage of customer issues resolved during the first interaction.

Formula: Resolved on first contact ÷ Total eligible cases × 100.

8. Root Cause Analysis

Finding the underlying reason for a failure rather than treating only its symptom.

Example: Repeated refund failures caused by an expired backend credential.

Production Example

Customer reports a failed refund.

Logs show the tool call. Traces identify the slow payment service. Metrics show increasing timeout rates. Root cause analysis identifies the backend problem.

Quick Revision

  • Logs = What happened?
  • Metrics = How much / how often?
  • Traces = Where did the request travel?
  • Evaluation = Was the answer correct?
  • Regression = Did the change break anything?
