📝 Prompting & Context

Quick CCAO-F Study Guide

1. What is Prompting?

A prompt is an instruction or input given to an AI model to produce a desired result.

Prompt → Model processes context → Response

2. Good Prompt

A good prompt clearly explains what to do, what context to use, and what output is expected.

Task + Context + Constraints + Output Format

3. Zero-Shot Prompting

Ask the model to perform a task without providing examples.

Example: “Classify this review as positive or negative.”

4. Few-Shot Prompting

Provide examples to show the model the expected pattern.

Example 1 → Input: Good → Output: Positive
Example 2 → Input: Bad → Output: Negative
New Input → Model predicts the pattern

5. What is Context?

Context is the information available to the model that helps it understand and complete the task.

Instructions + Conversation + Documents + Examples + Tool Results

6. Context Window

The context window is the amount of information a model can consider within a request or conversation.

Too much irrelevant context can make it harder to focus on the important information.

7. Context Engineering

Context engineering means deliberately selecting, organizing, and managing the information given to an agent or model.

Goal: Give the right information at the right time.

8. Task Decomposition

Break a large task into smaller, manageable steps.

Large Task → Step 1 → Step 2 → Step 3 → Final Result

🧠 Exam Memory

Prompt = Instruction | Context = Relevant information | Zero-shot = No examples | Few-shot = Examples | Context window = Information capacity | Context engineering = Manage the right context.
