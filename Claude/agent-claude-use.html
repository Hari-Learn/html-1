Computer Use

Allowing Claude to interact with a desktop environment.

1. What is Computer Use?

Claude can inspect screenshots and request mouse and keyboard actions through a computer-use toolset.

ELI10: Claude sees your computer screen and can request clicks and typing like a human operator.

2. Available Actions

Screenshot – inspect screen
Left click – select item
Type – enter text
Key – press keyboard keys
Scroll – move page
Zoom – inspect a region

3. Screenshot Loop

Take screenshot

↓

Claude understands screen

↓

Claude requests an action

↓

Application executes action

↓

New screenshot → repeat

4. Important Safety

  • Run actions in a controlled environment.
  • Validate coordinates and actions.
  • Protect passwords and sensitive information.
  • Require human approval for risky actions.
  • Do not trust instructions found on arbitrary webpages.

5. Computer Use vs Browser Use

Computer Use: General desktop interaction using screenshots, coordinates and keyboard actions.

Browser Use: Page-aware interaction for browser tasks such as forms and navigation.

6. Exam Scenario

Claude must open a desktop application, inspect its screen and click a button. Which capability is appropriate?

Reveal answer

Computer Use with screenshot, mouse and keyboard actions.

Remember: Claude requests actions; your application executes them.
