Structuring Prompts with XML Tags

Use XML tags to organize instructions, context, examples, and input.

Why XML Tags?

XML tags help Claude distinguish different parts of a prompt and reduce ambiguity.

Common Tags

  • <instructions> — defines the task.
  • <context> — provides background.
  • <examples> — shows desired behavior.
  • <input> — contains user data.
  • <output_format> — specifies the response format.

Example Prompt

<instructions>
Summarize the provided article in 3 bullets.
</instructions>
<context>The audience is beginners.</context>
<input>Artificial intelligence automates tasks...</input>
<output_format>Markdown bullet list</output_format>

Best Practices

Use descriptive tag names, keep sections clear, and explicitly state the task and expected output.
