Model Context Protocol

MCP is an open protocol that standardizes how AI applications connect to external tools, resources, and data sources.

MCP architecture

🤖

AI application

🔌

MCP Client

Manages connection

🛠️

MCP Server

Provides capabilities

Core concepts

Tools: Functions an AI application can invoke.

Resources: Contextual data exposed by servers.

Prompts: Reusable prompt templates offered by servers.

Transports: Methods used to communicate between components.

Real-world applications

Connecting AI assistants to databases, local files, developer tools, APIs, and business applications.
