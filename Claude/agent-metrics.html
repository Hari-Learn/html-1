Agent Evaluation & Metrics

How to measure whether an agent is actually performing well

Why Evaluate?

A demo may work once, but a production agent must work reliably across many situations.

Evaluation helps find weaknesses before real users experience them.

Core Metrics

  • Task success rate
  • Accuracy
  • First-contact resolution
  • Tool call success rate
  • Latency / response time
  • Cost per task
  • Safety / policy violations

Trade-offs

Improving one metric can hurt another.

  • More thinking → better reasoning but higher latency
  • More retries → better recovery but more cost
  • More tools → greater capability but more risk
  • More strict rules → safer but less flexibility

Evaluation Approach

  • Build representative test cases
  • Include edge cases and failures
  • Test with real-world scenarios
  • Compare against a baseline
  • Track changes across versions

Exam Insight

Choose the metric that matches the actual problem. Don't optimize only speed or cost when the real issue is task success, safety or reliability.
