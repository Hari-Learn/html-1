Claude API Learning

Lesson 01: Messages

User and Assistant Messages

Claude communicates using messages. A user sends a question and the assistant generates an answer.

How messages work

User: What is JavaScript?
Assistant: JavaScript is a programming language used to make websites interactive.

API Example

{
  "model": "claude-sonnet-4-5",
  "max_tokens": 1024,
  "messages": [
    {
      "role": "user",
      "content": "What is JavaScript?"
    }
  ]
}

Remember

  • User means the person asking a question.
  • Assistant means Claude responding.
  • Messages contain roles and content.
  • The conversation can contain multiple messages.
