Claude API & Model Engineering

Rare concepts that are easy to overlook.

1. Prompt Caching

Reuses eligible repeated prompt content to reduce processing time and cost.

  • Useful for repeated system instructions.
  • Useful for large reference documents.
  • Dynamic user input should generally follow stable content.
  • Not the same as long-term memory.

Exam trap: Caching does not mean Claude remembers everything forever.

2. Batch Processing

Processes multiple independent requests asynchronously.

  • Bulk document classification.
  • Large-scale sentiment analysis.
  • Offline evaluation.
  • Not suitable when an immediate response is required.

Exam trap: Batch API is not the same as parallel tool calls.

3. Streaming Responses

Claude sends response pieces as they are generated.

  • Improves perceived responsiveness.
  • Useful for long responses.
  • Applications must handle partial events.
  • Partial output does not guarantee successful completion.

4. Structured Outputs

Produces data in a predictable structure such as JSON.

  • Useful for API integrations.
  • Define required fields and data types.
  • Validate business rules separately.
  • Valid JSON does not guarantee correct information.

5. Thinking & Effort

Allocate more reasoning effort to complex tasks and less to simple tasks.

Low

Simple classification and extraction.

Medium

Comparisons and planning.

High

Complex analysis and debugging.

Exam trap: More effort can increase latency and cost.

Quick Revision

Caching = Reuse context

Batch = Many non-urgent requests

Streaming = Progressive output

Structured output = Predictable data

Thinking effort = Match reasoning to complexity
