CLAUDE AI · MODULE 02

Step-by-Step Task Instructions

Break complex requests into clear, verifiable stages.

Example prompt

Task: Analyze monthly sales data.
1. Validate the input data.
2. Calculate monthly totals.
3. Identify trends and anomalies.
4. Summarize findings with evidence.
5. State assumptions and uncertainties.
Output: A concise report with a table.

Reasoning alternatives

✓ Request a concise explanation of the method.
✓ Ask for calculations, evidence, and assumptions.
✓ Require validation against explicit criteria.

Tip: Request useful results and verifiable steps, not hidden internal reasoning.
