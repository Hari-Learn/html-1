2. Choosing the Right Model

Requirement Consider Reason
Complex reasoning Opus Higher capability for difficult tasks
General applications Sonnet Good balance of quality and efficiency
High-volume simple tasks Haiku Fast and efficient processing
Exam concept: Model selection is a trade-off involving capability, latency, and cost.

3. Claude API & Model

The Claude API allows applications to communicate with Claude programmatically.

📤

Request

Application sends instructions and data.

🤖

Claude

Selected model processes the request.

📥

Response

Application receives generated output. 

{
  "model": "claude-model-id",
  "max_tokens": 1024,
  "messages": [
    {
      "role": "user",
      "content": "Explain APIs simply."
    }
  ]
}

4. API Message Roles

USER

Contains the user's request, question, data, or task instructions.

ASSISTANT

Represents Claude's response or previous assistant conversation content.

SYSTEM

Provides high-level behavior, role, rules, and context for Claude.

5. System Prompts

A system prompt establishes the behavior and operating context that Claude should follow.

Example

"You are a concise technical tutor. Explain concepts using simple examples."

Remember: System instructions and user task instructions serve different purposes in an API interaction.

6. API Request Parameters

model

Specifies which Claude model should process the request.

max_tokens

Sets the maximum number of output tokens requested.

messages

Contains the conversation input.

system

Supplies high-level instructions and context.
