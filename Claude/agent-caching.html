Prompt Caching & Batch API

Reduce repeated work and handle large workloads.

1. Prompt Caching

Caching reuses eligible, repeated prompt content instead of processing the same context from scratch every time.

Best use cases

  • Large system instructions
  • Repeated reference documents
  • Common tool definitions
  • Stable project context
Remember:

Cache stable content. Put frequently changing content later.

2. Message Batches API

Processes many independent requests asynchronously when immediate responses are not required.

1. Submit
2. Process
3. Retrieve

Example: Classifying thousands of customer feedback messages.

Exam Comparison

Prompt caching: Repeated context.

Batch API: Large volume, no immediate response needed.

Normal API: Interactive, immediate response required.

Scenario Question

An application sends the same 30-page policy document with thousands of questions. What should you consider?

Reveal Answer

Prompt caching, because the reference context is repeatedly reused.
