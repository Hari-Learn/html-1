CLAUDE • AGENT ARCHITECTURE

🧠 Agent Architecture

Planning, memory, tools, and multiple agents.

5. 🧠 Agent Planning

Planning means deciding what steps should be taken to reach a goal.

Goal→ Break into tasks→ Choose actions→ Execute

Planning can be fixed beforehand or generated dynamically by the agent.

6. 📌 Agent State & Memory

State

Information about the current task, progress, tool results, and active context.

Memory

Information retained for use beyond the immediate step or interaction.

Simple idea: State = "What is happening now?" • Memory = "What should I remember?"

7. 🛠️ Tool Orchestration

The agent selects and coordinates tools to complete a task.

🔎 Search
🧮 Calculator
🗄️ Database
🔌 API

Orchestration decides which tool to call, in what order, and how to use each result.

8. 👥 Multi-Agent Systems

Multiple specialized agents cooperate on a larger task.

🧑‍💻 Research Agent
✍️ Writing Agent
🔍 Review Agent
🎯 Coordinator

Each agent can have a specialized role, tools, instructions, and responsibilities.

🔄 Example

Research Agent → collects information → Writing Agent creates draft → Review Agent checks result.

🧠 Memory: Planning = decide steps • State = current progress • Tools = actions • Multi-agent = specialized agents working together.
