Context Editing & Compaction

Managing long-running Claude conversations and agent tasks.

1. The Problem

Long-running agents accumulate messages, screenshots, tool results and other content.

ELI10: Your school bag becomes full of old notebooks. You need to organise it to make room for new books.

2. Context Editing

Context editing selectively clears old content that is no longer needed.

  • Clear older tool results.
  • Manage older thinking blocks.
  • Preserve recent useful information.

It removes selected content; it does not necessarily summarise the conversation.

3. Compaction

Compaction replaces older conversation history with a summary so the agent can continue its task.

4. Key Difference

Context editing

Removes selected old content, such as bulky tool results.

Compaction

Summarises older history and replaces it with a compact representation.

5. When to Use?

  • Large research tasks with many search results.
  • Agents processing hundreds of files.
  • Long-running tool workflows.
  • Conversations approaching context limits.

6. Exam Scenario

An agent has analysed 100 files. The conversation is becoming too large, but the agent must continue its work. Which technique replaces older history with a summary?

Reveal answer

Compaction. It summarises older conversation history so the agent can continue with a smaller context.

Remember: Editing = clear selected content. Compaction = summarise older history.
