🤖 Models & Model Selection

Quick CCAO-F Study Guide

1. What is an AI Model?

An AI model is a trained system that processes input and produces an output based on learned patterns.

Input → Model → Output

2. Claude Model Family

Opus

Designed for highly complex reasoning and demanding tasks.

Sonnet

Balances capability, speed and cost for many workloads.

Haiku

Designed for fast, efficient workloads where low latency matters.

3. Model Selection

Choose a model based on the task requirements, not simply because one model is more powerful.

Task complexity + Quality needed + Speed + Cost + Scale

4. When to Choose a More Capable Model?

  • Complex reasoning
  • Hard coding problems
  • Multi-step analysis
  • Tasks where higher capability is important

5. When to Choose a Faster Model?

  • Simple classification
  • High-volume requests
  • Low-latency applications
  • Cost-sensitive workloads

6. Example

Suppose you need to classify 1 million customer messages as complaint / not complaint.

Simple + High Volume + Fast Response → Consider an efficient, fast model.

7. Model Selection Rule

Start with the simplest/most efficient model that reliably meets your quality requirements.

🧠 Exam Memory: Opus → Complex | Sonnet → Balance | Haiku → Speed & efficiency | Selection → Quality + Cost + Latency + Task complexity.
