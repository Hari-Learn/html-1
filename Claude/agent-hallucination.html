AI Reliability

Agent Hallucination

An AI agent hallucination occurs when an agent generates information, actions, or conclusions that are incorrect, unsupported, or fabricated.

⚠️

False Facts

The agent presents incorrect information as if it were factual.

🔗

Fake Sources

The agent may invent citations, references, links, or supporting evidence.

🤖

Wrong Actions

An agent can make incorrect assumptions while planning or using tools.

How to Reduce Hallucinations

Grounding

Connect responses to trusted, relevant data sources.

Verification

Validate important claims before using them.

Tool Controls

Restrict and validate agent tool calls and their inputs.

Human Review

Require human approval for high-impact decisions or actions.

🛡️

Key Principle

Treat confident AI output as a claim that may need verification, especially when accuracy or real-world actions matter.
