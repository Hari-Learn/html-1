CLAUDE API · LESSON 06

Tool Use & Function Calling

Let Claude request external tools to perform tasks and retrieve data.

1. Define

Describe the tool and its input schema.

2. Request

Claude returns a tool-use request.

3. Execute

Your application runs the tool and returns results.

Example: Calculator Tool

import anthropic

client = anthropic.Anthropic()

tools = [{
    "name": "add_numbers",
    "description": "Add two numbers.",
    "input_schema": {
        "type": "object",
        "properties": {
            "a": {"type": "number"},
            "b": {"type": "number"}
        },
        "required": ["a", "b"]
    }
}]

response = client.messages.create(
    model="claude-sonnet-4-5",
    max_tokens=200,
    tools=tools,
    messages=[{
        "role": "user",
        "content": "What is 12 plus 8?"
    }]
)

for block in response.content:
    if block.type == "tool_use":
        result = block.input["a"] + block.input["b"]
        print("Tool result:", result)

Production Note

This example demonstrates tool request detection and execution. A complete tool loop must send the tool result back to Claude in a user message containing a tool_result block, then handle further responses.
