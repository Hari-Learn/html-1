```html Agent Permissions
🔐 Agent Permissions

What an agent is allowed to access and do

What are Agent Permissions?

Agent permissions define which resources and actions an agent is allowed to use.

Agent → Permission Check → Allowed Action

Examples of Permissions

📖 Read

Read documents, databases or files.

✏️ Write

Create or modify files and records.

🔧 Tool Access

Use APIs, search or external tools.

💻 Execute

Run commands or programs.

Least Privilege

Give the agent only the permissions it actually needs.

❌ Agent needs to read one file → Give access to the entire system

✅ Agent needs to read one file → Give access only to that file

This reduces accidental and unauthorized actions.

🧠 Remember: Permissions = What the agent is allowed to do.
Least Privilege = Give only the access it needs.
```
