DAY 1 • ADVANCED PROMPTING

Artifacts, Chaining, Evaluation & Injection

Turn individual prompts into repeatable and reliable workflows.

Artifacts

Artifacts are substantial outputs intended for continued use or editing, such as documents, code, diagrams, or structured deliverables.

Projects

Projects organize related work, instructions, files, and conversations around an ongoing goal, helping maintain relevant context.

Prompt Chaining

Use multiple prompts in sequence where one step's output becomes the next step's input:
Research → Extract → Analyze → Draft → Review.

Prompt Evaluation

Test prompts using a fixed test set and criteria such as correctness, completeness, format compliance, consistency, and groundedness.

Prompt Injection

Prompt injection is an attempt to manipulate an AI system through untrusted content or instructions.

1. Identify trusted instructions
2. Treat external content as untrusted data
3. Validate before taking action

Reusable Prompt Template

ROLE: You are a {role}.

TASK: {task}

CONTEXT:
{relevant_context}

CONSTRAINTS:
- {constraint_1}
- {constraint_2}

OUTPUT FORMAT:
{format}

QUALITY CHECK:
- Verify against the provided context.
- State uncertainty instead of inventing facts.

Day-1 Workflow

Define the task → add context → set constraints → choose role → use examples when useful → decompose complex work → ground the answer → evaluate → iterate.
