Tool-Use Cycle

Claude requests a tool, your application executes it, and Claude uses the result.

1. User Request

"What is the weather in Chennai?"

↓
2. Claude Tool Call

get_weather(city="Chennai")

↓
3. Application Executes Tool

Calls the weather service and obtains results.

↓
4. Tool Result and Final Answer

The result is returned to Claude, which responds to the user.

Important: Claude requests tool execution; your application runs the tool and sends back its result.
