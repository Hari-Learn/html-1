MODULE 01

Installing Claude Code

Set up your environment and get ready for AI-powered coding.

1. Check Requirements

  • • Internet connection
  • • Supported operating system
  • • Claude account
  • • Terminal or command prompt

2. Install Claude Code

Use the official installation instructions for your operating system.

curl -fsSL https://claude.ai/install.sh | bash

For macOS/Linux. Review official installation guidance before running commands.

3. Verify Installation

claude --version

4. Configure Authentication

Run Claude Code and follow the authentication instructions to connect your account.

claude
