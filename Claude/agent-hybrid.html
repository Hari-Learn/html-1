Hybrid Search

Hybrid search combines keyword-based BM25 search with semantic vector search to improve retrieval accuracy.

Hybrid Search Architecture

BM25 Search

Keyword matching

Semantic Search

Meaning matching

↓

Result Fusion

Combine and rank results

↓
Final Relevant Results

How It Works

  1. Receive the user's query.
  2. Run BM25 keyword search.
  3. Run semantic vector search.
  4. Combine retrieved results.
  5. Apply score fusion or reranking.
  6. Return the most relevant documents.

Fusion Technique

Reciprocal Rank Fusion (RRF)

RRF combines rankings from multiple search methods using their rank positions.

RRF(d) = Σ 1 / (k + rank(d))

Advantages

Combines exact keyword matching with contextual understanding.

Limitations

More complex and resource-intensive to implement.

Applications

Enterprise search, RAG applications, AI assistants, and intelligent knowledge management.
