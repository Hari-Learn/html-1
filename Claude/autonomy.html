What is Agent Autonomy?

Agent autonomy means how independently an AI agent can make decisions and take actions without asking a human every time.

Human gives Goal → Agent Decides → Agent Acts → Agent Checks

More autonomy = more freedom to act + more responsibility and risk.

Autonomy Levels

Level 0

Human does the work.

Agent only provides information.

Level 1

Agent suggests actions.

Human makes the final decision.

Level 2

Agent acts with approval.

Human approves important actions.

Level 3

Agent acts independently.

Human supervises exceptions.

🧠 Remember: Autonomy = How much freedom an agent has to decide and act.
