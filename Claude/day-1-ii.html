DAY 1 • MODEL BEHAVIOR

Context, Tokens & Reliability

Understand how model context and generation affect prompt results.

Context Window

The context window is the amount of input and output information a model can handle in a request or conversation. More context is useful, but relevant context is more valuable than unnecessary content.

Token

A token is a unit used by the model to process text. Words, parts of words, punctuation, and spaces may be represented by different token units. Token count is not the same as word count.

Temperature

Temperature is a generation-control setting in systems that expose it. Lower values generally produce more focused and predictable outputs; higher values can increase variation.

Hallucination

A hallucination is a response that sounds plausible but contains unsupported, fabricated, or incorrect information.

Grounding

Grounding means connecting the response to trusted information or supplied evidence. Example: "Answer only from the provided document. If the answer is absent, say so."

Task Decomposition

Break a complex task into smaller steps:
Extract facts → Classify → Analyze → Draft → Check constraints → Final answer.

Iteration

Prompting is iterative: create a prompt → inspect output → identify failure → improve instructions/context/examples → test again.
