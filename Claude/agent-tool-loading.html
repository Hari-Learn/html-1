Claude API: Deferred Tool Loading

Rare Topic 23 | CCAO-F Notes

1. What does deferred mean?

Deferred means postponed or delayed until needed.

Deferred Tool Loading means some tool definitions are not loaded into the initial context. They can be discovered and loaded later.

2. The key setting

"defer_loading": true

This marks a tool for deferred loading in supported tool-search workflows.

It does not mean the tool is permanently disabled.

3. Typical workflow

1. Load a small set of essential tools.
↓
2. Keep other tools deferred.
↓
3. Claude searches for a needed tool.
↓
4. The discovered tool becomes available.

4. Why use it?

  • Large tool collections.
  • Less upfront tool-definition context.
  • Load specialised tools only when required.
  • Keep frequently used tools available from the start.

5. Tool Search vs Deferred Loading

Tool Search: finds the relevant tool.

Deferred Loading: postpones loading its definition until it is needed.

They work together, but they are not the same feature.

ELI10 Example

You have a toolbox with 100 tools. Keep your screwdriver and hammer on the table. Keep the other 98 in a cupboard. Bring one out only when a job requires it.

Exam Scenario

An application has 200 specialised tools, but most requests need only two or three. The developer wants to postpone loading unused tool definitions. Which setting is relevant?

Reveal answer

defer_loading: true, used with a supported tool-discovery workflow.
